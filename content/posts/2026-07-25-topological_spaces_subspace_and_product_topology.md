בפוסטים האחרונים התחלנו לדבר על מרחבים טופולוגיים בדרך המקובלת במתמטיקה: נתנו הגדרה ("קבוצות פתוחות"), ראינו כמה דוגמאות ("מרחבים מטריים", "טופולוגיית הסדר") ודיברנו על פונקציות שמשמרות מבנה ("הומיאומורפיזמים"). מה עכשיו, מה עכשיו, מה עכשיו? אה, כמובן, איך שכחנו את החלק הכי כיפי - איך בונים מרחבים חדשים מתוך מרחבים קיימים.

למי שמכירים תורת הקבוצות, מה שנעשה פה לא הולך להיות מפתיע כי נשתמש בפעולות סטנדרטיות על קבוצות: ניקח **תת-קבוצות** וניקח **מכפלות** של קבוצות (במקור תכננתי גם לקחת **מנות** אבל הפוסט נהיה ארוך מדי גם ככה וזה נושא שאפשר לדבר עליו בנפרד). מה שהופך את זה למעניין הוא שעכשיו אנחנו צריכים למצוא דרך להגדיר **טופולוגיה** על הקבוצות שנקבל - אם כי הדרך הזו תהיה טבעית למדי (עבור מכפלות נראה שיש שתי דרכים ודווקא זו שנראית פחות טבעית היא השימושית והנפוצה). ומן הסתם, כדאי שיהיו לנו דוגמאות מול העיניים.

בואו נתחיל.

## טופולוגיית תת-המרחב

נתחיל עם הדבר המתבקש: יש לנו מרחב טופולוגי {% equation %}\left(X,\mathcal{T}_{X}\right){% endequation %} ויש לנו תת-קבוצה {% equation %}Y\subseteq X{% endequation %} . איך נהפוך את {% equation %}Y{% endequation %} למרחב טופולוגי בפני עצמו, כלומר איך נגדיר {% equation %}\mathcal{T}_{Y}{% endequation %} בצורה "טבעית" שתשמור על הדמיון ל-{% equation %}X{% endequation %} ? ובכן, זה קל:

- {% equation %}\mathcal{T}_{Y}=\left\{ U\cap Y\ |\ U\in\mathcal{T}_{X}\right\}{% endequation %} 

לא קשה להראות שאם יש לנו בסיס {% equation %}\mathcal{B}{% endequation %} של {% equation %}X{% endequation %}, אז {% equation %}\left\{ B\cap Y\ |\ B\in\mathcal{B}\right\}{% endequation %} הוא בסיס של {% equation %}Y{% endequation %} עם טופולוגיית תת-המרחב, כלומר קל לנו גם לדעת איך בסיס ל-{% equation %}Y{% endequation %} נראה אם אנחנו מכירים בסיס ל-{% equation %}X{% endequation %} .

הנה דוגמא פשוטה שכבר דיברנו עליה כשראינו את טופולוגיית הסדר. ניקח את {% equation %}X=\mathbb{R}{% endequation %} עם הטופולוגיה הרגילה, כלומר זו שהקטעים הפתוחים הם בסיס עבורה, וניקח את תת-המרחב {% equation %}Y=\mathbb{R}^{\ge0}{% endequation %}, כלומר כל המספרים הממשיים האי-שליליים. אז עכשיו למשל הקבוצה הפתוחה {% equation %}\left(-1,1\right){% endequation %}, כשחותכים אותה עם {% equation %}Y{% endequation %}, נותנת את {% equation %}[0,-1){% endequation %}, כלומר את הקטע החצי פתוח והחצי **סגור**. זה תואם את מה שראינו עם טופולוגיית הסדר, שבה כשהיה איבר מינימלי היינו צריכים לקחת בתור קבוצות פתוחות גם את הקטעים הסגורים שמתחילים בו. באופן כללי, הבסיס לטופולוגייה הזו יכלול את כל הקטעים מהצורה {% equation %}[0,a){% endequation %} עבור {% equation %}a\gt 0{% endequation %} ואת כל הקטעים מהצורה {% equation %}\left(a,b\right){% endequation %} עבור {% equation %}0\lt a\lt b{% endequation %} - בדיוק כמו טופולוגיית הסדר.

יש כאן משהו טיפה טריקי - {% equation %}[0,-1){% endequation %} היא קבוצה פתוחה ב-{% equation %}Y{% endequation %} אבל היא **לא** קבוצה פתוחה ב-{% equation %}X{% endequation %} (כי ב-{% equation %}X{% endequation %} אין ל-0 סביבה שכולה מוכלת ב-{% equation %}X{% endequation %} ). אז צריך להיות זהירים בסיטואציות עם תתי-מרחבים וכשאומרים שקבוצה היא "פתוחה" צריך להסביר איפה. מה שכן, קל לנחש איזה תנאי צריך לדרוש על {% equation %}Y{% endequation %} כדי להבטיח שכל קבוצה פתוחה ב-{% equation %}Y{% endequation %} תהיה פתוחה גם ב-{% equation %}X{% endequation %} - אם {% equation %}Y{% endequation %} עצמו פתוחה ב-{% equation %}X{% endequation %} אז מן הסתם גם החיתוך {% equation %}U\cap Y{% endequation %} יהיה פתוח ב-{% equation %}X{% endequation %} לכל {% equation %}U{% endequation %} שפתוחה ב-{% equation %}X{% endequation %} (כי חיתוך שתי קבוצות פתוחות הוא קבוצה פתוחה).

עד כאן הכל פשוט וברור, נכון? אבל זו טופולוגיה. בטופולוגיה הכל משוגע. הדוגמא שנתתי למעלה היא **פשוטה מדי**. היא נותנת את הרושם שאם יש לי קבוצה סדורה {% equation %}X{% endequation %} עם טופולוגיית הסדר עליה, ואני מסתכל על תת-קבוצה {% equation %}Y{% endequation %}, אז אני אקבל את אותה טופולוגיה עליה בשתי דרכים שונות:

- אני אגדיר על {% equation %}Y{% endequation %} את טופולוגיית תת-המרחב בהתאם לטופולוגיית הסדר שיש על {% equation %}X{% endequation %} .

- אני אגדיר על {% equation %}Y{% endequation %} את טופולוגיית הסדר בהתאם ליחס הסדר שיש על {% equation %}X{% endequation %} .

בגישה הראשונה מתחילים מיחס סדר על {% equation %}X{% endequation %} ; הוא מייצר טופולוגיה על {% equation %}X{% endequation %} ; ואז {% equation %}X{% endequation %} "מוריש" את **הטופולוגיה** שלו ל-{% equation %}Y{% endequation %} . בגישה השניה גם מתחילים מיחס סדר על {% equation %}X{% endequation %}, ואז {% equation %}X{% endequation %} "מוריש" את **יחס הסדר** שלו ל-{% equation %}Y{% endequation %} ; ואז יחס הסדר הנורש מייצר טופולוגיה על {% equation %}Y{% endequation %} .

באופן כללי שתי השיטות הללו יכולות **לתת דברים שונים**.

בואו נראה דוגמא. לא צריך ללכת רחוק: אפשר להתחיל עם {% equation %}X=\mathbb{R}{% endequation %} אבל בתור {% equation %}Y{% endequation %} להצטמצם קצת יותר מאשר סתם לחתוך את {% equation %}X{% endequation %} באמצע. ספציפית, בואו ניקח גם **סינגלטון**. נגדיר

{% equation %}Y=[0,1)\cup\left\{ 2\right\}{% endequation %} עכשיו, בטופולוגיית תת-המרחב, מכיוון ש-{% equation %}\left(1,3\right)\cap Y=\left\{ 2\right\}{% endequation %} ו-{% equation %}\left(1,3\right){% endequation %} פתוחה ב-{% equation %}X{% endequation %}, נקבל ש-{% equation %}\left\{ 2\right\}{% endequation %} פתוחה ב-{% equation %}Y{% endequation %} . מצד שני, {% equation %}Y{% endequation %} יורש את יחס הסדר "הרגיל" של {% equation %}X{% endequation %} . על פי טופולוגיית הסדר, הקבוצות הפתוחות של {% equation %}Y{% endequation %} הן כל הקטעים מהצורה {% equation %}\left(a,b\right){% endequation %} כך ש-{% equation %}a\lt b\in Y{% endequation %} ובנוסף לכך, מכיוון ש-{% equation %}2{% endequation %} הוא האיבר הגדול ביותר, כל הקטעים מהצורה {% equation %}(a,2]{% endequation %} עבור {% equation %}a\in Y{% endequation %} . למשל, {% equation %}(\frac{1}{2},2]=\left(\frac{1}{2},1\right)\cup\left\{ 2\right\}{% endequation %} הולך להיות קבוצה פתוחה, אבל {% equation %}\left\{ 2\right\}{% endequation %} עצמו? לא. אין שום דרך לקבל אותו בתור {% equation %}(a,2]{% endequation %} . מה שחמוד כאן במיוחד הוא שאם תת-המרחב שלנו היה {% equation %}Y=\left[0,1\right]\cup\left\{ 2\right\}{% endequation %}, אז דווקא היה אפשר לקחת את {% equation %}(1,2]=\left\{ 2\right\}{% endequation %} בתור איבר בסיס; אבל מכיוון ש-{% equation %}Y=[0,1)\cup\left\{ 2\right\}{% endequation %}, אז {% equation %}1{% endequation %} הוא בכלל לא חלק מהמרחב ואי אפשר לקחת קטע שמתחיל בו.

אוקיי, זה מוזר. האם אפשר למצוא קריטריון שיבטיח לנו שהמוזר הזה לא מתרחש? כן, זה לא קשה במיוחד. בדוגמא הנגדית שלנו הבעיה הייתה הניתוק הזה בין 2 ובין שאר המרחב. כדי למנוע מזה להתרחש, אפשר לדרוש שהמרחב יהיה **קבוצה קמורה** - הרעיון בקבוצה כזו באופן כללי הוא שעבור כל שתי נקודות, הקו שמחבר אותן עובר כולו בתוך הקבוצה. בהקשר שלנו, של קבוצות סדורות לינארית, תת-הקבוצה {% equation %}Y\subseteq X{% endequation %} היא **קמורה** ב-{% equation %}X{% endequation %} אם לכל {% equation %}a,b\in Y{% endequation %} מתקיים {% equation %}\left(a,b\right)\subseteq Y{% endequation %}, כאשר {% equation %}\left(a,b\right)=\left\{ x\in X\ |\ a\lt x\lt y\right\}{% endequation %} (כלומר - אנחנו מסתכלים על כל הנקודות של המרחב הגדול {% equation %}X{% endequation %}, לא רק על אלו ששייכות ל-{% equation %}Y{% endequation %} ).

בואו נוכיח שאם {% equation %}Y{% endequation %} קמורה ב-{% equation %}X{% endequation %}, אז שתי הטופולוגיות שאפשר לקבל בדרכים שתיארתי קודם הן זהות. איך מראים שטופולוגיות הן זהות? אפשר לקחת קבוצה פתוחה כללית בטופולוגיה אחת ולהראות שהיא פתוחה בטופולוגיה השניה, אבל זה יכול להיות קשה כי קבוצה פתוחה כללית זה משהו מסובך. בשביל זה יש לנו בסיסים ותת-בסיסים, כדי לפשט הוכחות כאלו. אם יש לנו שתי טופולוגיות {% equation %}\mathcal{T}_{1},\mathcal{T}_{2}{% endequation %} ויש לנו איבר {% equation %}U\in\mathcal{T}_{1}{% endequation %} ששייך לתת-בסיס לטופולוגיה {% equation %}\mathcal{T}_{1}{% endequation %} ואנחנו מראים ש-{% equation %}U\in\mathcal{T}_{2}{% endequation %}, סיימנו; כי כל איבר ב-{% equation %}\mathcal{T}_{1}{% endequation %} אפשר לכתוב בתור חיתוכים סופיים ואיחודים של איבר תת-בסיס של {% equation %}\mathcal{T}_{1}{% endequation %}, ואם כל האיברים הללו הם פתוחים ב-{% equation %}\mathcal{T}_{2}{% endequation %} גם כל חיתוך סופי ואיחוד שלהם יהיה כזה.

עבור טופולוגיית הסדר, תת-הבסיס בנוי על **קרניים**, קבוצות מהצורה {% equation %}\left(a,\infty\right){% endequation %} ו-{% equation %}\left(-\infty,b\right){% endequation %} . מספיק להראות ש-{% equation %}\left(a,\infty\right){% endequation %} פתוחה גם בטופולוגיית תת-המרחב, כי ההוכחה עבור {% equation %}\left(-\infty,b\right){% endequation %} תהיה סימטרית. 

עכשיו, בואו נסתכל על זה בזהירות. אני לקחתי את הקרן {% equation %}\left(a,\infty\right){% endequation %}, אבל **באיזה מרחב**? אני כרגע במרחב {% equation %}Y{% endequation %} שהוא תת-קבוצה של {% equation %}X{% endequation %} עם יחס הסדר שירשנו מ-{% equation %}X{% endequation %} . כלומר הקרן היא

{% equation %}\left(a,\infty\right)=\left\{ y\in Y\ |\ a\lt y\lt \infty\right\}{% endequation %} עכשיו, כל איבר של {% equation %}Y{% endequation %} הוא גם איבר של {% equation %}X{% endequation %} אז אפשר לכתוב

{% equation %}\left(a,\infty\right)=\left\{ x\in X\ |\ a\lt x\lt \infty\right\} \cap Y{% endequation %} אבל הקבוצה {% equation %}\left\{ x\in X\ |\ a\lt x\lt \infty\right\}{% endequation %} היא קרן במרחב {% equation %}X{% endequation %}, ולכן אם לוקחים את טופולוגיית הסדר על {% equation %}X{% endequation %}, הקבוצה הזו תהיה פתוחה ב-{% equation %}X{% endequation %}, ולכן החיתוך שלה עם {% equation %}Y{% endequation %} יהיה פתוח ב-{% equation %}Y{% endequation %} **בטופולוגיית תת-המרחב**, שזה מה שרצינו להראות.

עכשיו נלך על הכיוון השני - ניקח את {% equation %}Y{% endequation %} עם טופולוגיית תת המרחב. האם יש לנו תת-בסיס עבור הטופולוגיה הזו? בערך: אנחנו יודעים שכל קבוצה פתוחה ב-{% equation %}Y{% endequation %} מתקבלת מחיתוך של {% equation %}Y{% endequation %} עם קבוצה פתוחה ב-{% equation %}X{% endequation %}, ועל {% equation %}X{% endequation %} יש לנו תת-בסיס כי יש עליו את טופולוגיית הסדר. לכן, אם נחתוך את האיברים של כל תת-הבסיס הזה עם {% equation %}Y{% endequation %} נקבל תת-בסיס של {% equation %}Y{% endequation %} (כי כל קבוצה פתוחה ב-{% equation %}Y{% endequation %} מתקבלת מכך שעושים איחודים וחיתוכים סופיים של אברי תת הבסיס של {% equation %}X{% endequation %} **ובסוף** חותכים עם {% equation %}Y{% endequation %} ; אפשר גם לחתוך מראש עם {% equation %}Y{% endequation %} את כל הקבוצות המעורבות וזה יעבוד באותה מידה). תת-הבסיס של {% equation %}X{% endequation %} כולל קרניים, למשל מהצורה {% equation %}\left(a,\infty\right){% endequation %}, ולכן תת-הבסיס של {% equation %}Y{% endequation %} יכיל קבוצות מהצורה {% equation %}\left(a,\infty\right)\cap Y{% endequation %} . מה אנחנו יודעים על הקבוצות הללו?

ראשית, ייתכן כמובן ש-{% equation %}\left(a,\infty\right)\cap Y=\emptyset{% endequation %}, וזה בסדר כי זו קבוצה פתוחה. ייתכן גם ש-{% equation %}\left(a,\infty\right)\cap Y=\left(a,\infty\right){% endequation %}, כלומר לא איבדנו איברים בחיתוך עם {% equation %}Y{% endequation %}, וגם זה בסדר כי קרניים ב-{% equation %}Y{% endequation %} הן פתוחות בטופולוגיית הסדר. הסיטואציה הבעייתית היא אם אחרי החיתוך אנחנו מקבלים משהו שהוא לא קרן ב-{% equation %}Y{% endequation %} . זו הדוגמא שראינו קודם: היה לנו את {% equation %}Y=[0,1)\cup\left\{ 2\right\}{% endequation %} ואם למשל נחתוך אותו עם {% equation %}\left(1,\infty\right){% endequation %} נקבל את {% equation %}\left\{ 2\right\}{% endequation %} שהיא לא קרן ב-{% equation %}Y{% endequation %} . זה משהו שבלבל גם אותי - מה זאת אומרת זו לא קרן ב-{% equation %}Y{% endequation %} ? למה אי אפשר להגיד שזו הקרן {% equation %}\left(1,\infty\right){% endequation %} ב-{% equation %}Y{% endequation %} ? אה! כי {% equation %}1\notin Y{% endequation %} אז אי אפשר להשתמש בו בתור נקודת קצה. תזכרו, קרן ב-{% equation %}Y{% endequation %} היא קבוצה מהצורה {% equation %}\left\{ y\in Y\ |\ y\gt a\right\}{% endequation %} עבור {% equation %}a\in Y{% endequation %}, וזה בדיוק מה שלא קורה כאן. אני יכול, כמובן, להסתכל על קרן כמו {% equation %}\left(\frac{1}{2},\infty\right){% endequation %}, אבל הבעיה היא שהקרן הזו תכיל **עוד** נקודות חוץ מאשר את 2 עצמה ולכן גם פה לא אקבל את {% equation %}\left\{ 2\right\}{% endequation %} . אז זו הבעיה - החיתוך {% equation %}\left(a,\infty\right)\cap Y{% endequation %} עלול במקרה הכללי לא להיות קרן, וצריך להשתמש בקמירות של {% equation %}Y{% endequation %} כדי להראות שהוא כן קרן.

אז מהי {% equation %}\left(a,\infty\right)\cap Y{% endequation %} אם {% equation %}Y{% endequation %} קמורה? אם {% equation %}a\in Y{% endequation %} אין שום בעיה, עדיין נקבל קרן: {% equation %}\left(a,\infty\right)\cap Y=\left\{ y\in Y\ |\ y\gt a\right\}{% endequation %} . זו קרן גם ב-{% equation %}Y{% endequation %} בזכות זה ש-{% equation %}a\in Y{% endequation %} . הבעיה היא אם {% equation %}a\notin Y{% endequation %}, אבל במקרה הזה {% equation %}a{% endequation %} לא יכול להיות ב"חור באמצע" של {% equation %}Y{% endequation %} בגלל הקמירות של {% equation %}Y{% endequation %} . כלומר, לא ייתכן שיש {% equation %}b,c\in Y{% endequation %} כך ש-{% equation %}b\lt a\lt c{% endequation %} כי אז היינו מקבלים ש-{% equation %}a\in Y{% endequation %} מהקמירות של {% equation %}Y{% endequation %} . אז יש בדיוק שתי אפשרויות: או שלכל {% equation %}b\in Y{% endequation %} מתקיים {% equation %}a\lt b{% endequation %}, או שלכל {% equation %}b\in Y{% endequation %} מתקיים {% equation %}b\lt a{% endequation %} . במקרה השני, {% equation %}\left(a,\infty\right){% endequation %} לא כוללת בכלל איברים של {% equation %}Y{% endequation %} (כי כל מה שיש שם גדול מ-{% equation %}a{% endequation %} שגדול מכל אברי {% equation %}Y{% endequation %} ) ולכן {% equation %}\left(a,\infty\right)\cap Y=\emptyset{% endequation %} וזה כאמור בסדר. במקרה הראשון, {% equation %}a{% endequation %} הוא חסם מלמטה של **כל**{% equation %}Y{% endequation %} ולכן {% equation %}\left(a,\infty\right){% endequation %} מכיל את **כל**{% equation %}Y{% endequation %} כך ש-{% equation %}\left(a,\infty\right)\cap Y=Y{% endequation %} וגם זה בסדר כי גם כל המרחב הוא קבוצה פתוחה. זה מסיים את ההוכחה הזו.

## טופולוגיית המכפלה - החלק הקל

אחת הבניות הבסיסיות של קבוצה חדשה מקבוצות קיימות היא **מכפלה קרטזית**. אם {% equation %}A,B{% endequation %} הן קבוצות כלשהן אז המכפלה הקרטזית שלהן היא {% equation %}A\times B=\left\{ \left(a,b\right)\ |\ a\in A,b\in B\right\}{% endequation %} כאשר {% equation %}\left(a,b\right){% endequation %} הוא **זוג סדור** של איברים. על ידי חזרה כמה פעמים על אותו טריק, אפשר לבנות מכפלות קרטזיות של מספר סופי כלשהו של קבוצות, {% equation %}A_{1}\times A_{2}\times\ldots\times A_{n}{% endequation %} הוא אוסף כל ה-{% equation %}n{% endequation %} -יות הסדורות {% equation %}\left(a_{1},\ldots,a_{n}\right){% endequation %} כך ש-{% equation %}a_{i}\in A_{i}{% endequation %} . הבניה הזו היא מאוד שימושית - באלגברה לינארית רואים בערך מהרגע הראשון איך בונים את {% equation %}\mathbb{R}^{n}{% endequation %}, המרחב הממשי ה-{% equation %}n{% endequation %} -ממדי שמכליל את הישר הממשי והמישור הממשי. בלינארית מגדירים **מבנה אלגברי** על הקבוצה הזו, כלומר פעולות של חיבור וכפל בסקלר; אנחנו רוצים להגדיר **טופולוגיה** על הקבוצות הללו, בהנחה שכבר יש טופולוגיה על כל קבוצה בנפרד. איך נעשה את זה? ובכן, זה אחד מהמקרים שבהם ההגדרה ה"טבעית" היא גם זו המתבקשת - אבל רק כל עוד אנחנו **במקרה הסופי**. בקרוב דברים יתחילו להסתבך.

אם כן, בואו נתחיל ממה שקל. נניח שיש לנו שני מרחבים טופולוגיים {% equation %}\left(X,\mathcal{T}_{X}\right),\left(Y,\mathcal{T}_{Y}\right){% endequation %} . אנחנו לוקחים את המכפלה {% equation %}X\times Y{% endequation %} ומגדירים עליה טופולוגיה, {% equation %}\mathcal{T}{% endequation %} על ידי זה שניקח בתור בסיס {% equation %}\mathcal{B}{% endequation %} לטופולוגיה את

- {% equation %}\mathcal{B}=\left\{ U\times V\ |\ U\in\mathcal{T}_{X},V\in\mathcal{T}_{Y}\right\}{% endequation %} 

כלומר, הקבוצות הפתוחות הבסיסיות שלנו יהיו מכפלות של קבוצות פתוחות משני המרחבים. שימו לב שזה רק **בסיס**, זה לחלוטין לא תיאור של כל הקבוצות בטופולגיה; בכל מכפלה קרטזית יש הרבה מאוד תת-קבוצות שאי אפשר לתאר בתור מכפלה של קבוצה מפה וקבוצה משם (למשל, במכפלה {% equation %}A^{2}{% endequation %} אין דרך לתאר את הקבוצה {% equation %}\left\{ \left(a,a\right)\ |\ a\in A\right\}{% endequation %} בתור {% equation %}U\times V{% endequation %} אם {% equation %}A{% endequation %} כוללת יותר מאיבר אחד), אבל אנחנו כן אומרים שכל קבוצה פתוחה יכולה להתקבל על ידי איחוד אינסופי של קבוצות בסיס. למשל, ב-{% equation %}\mathbb{R}^{2}{% endequation %} כל איבר מהצורה {% equation %}U\times V{% endequation %} הוא **מלבן** (מלבן פתוח; כלומר, בלי השפה שלו) אבל אם נאחד אינסוף מלבנים שייבחרו בצורה זהירה נוכל לקבל עיגול פתוח.

כזכור, אי אפשר סתם לקרוא בשם "בסיס" לכל קבוצה, יש שתי דרישות שצריכות להתקיים. אחת היא שכל איבר במרחב יהיה שייך לאחת מהקבוצות וזה כמובן עובד כאן כי {% equation %}X\times Y{% endequation %} עצמה היא איבר בסיס. הדרישה השניה טיפה יותר טריקית: אם {% equation %}B_{1},B_{2}{% endequation %} הם אברי בסיס ו-{% equation %}x\in B_{1}\cap B_{2}{% endequation %} אז צריך להראות שקיים איבר בסיס {% equation %}B{% endequation %} כך ש-{% equation %}x\in B\subseteq B_{1}\cap B_{2}{% endequation %} . במקרה שלנו זה עובד כי {% equation %}B_{1}\cap B_{2}{% endequation %} הוא די פשוט עבור קבוצות שהן מכפלה - זה שוב פעם תורת קבוצות בסיסית בפעולה:

{% equation %}\left(U_{1}\times V_{1}\right)\cap\left(U_{2}\times V_{2}\right)=\left(U_{1}\cap U_{2}\right)\times\left(V_{1}\cap V_{2}\right){% endequation %} לכן תמיד אפשר לבחור {% equation %}B=B_{1}\cap B_{2}{% endequation %} כי גם הוא איבר בסיס, וזה מסיים את הסיפור הזה.

מה קורה אם לוקחים את {% equation %}\mathbb{R}{% endequation %} עם הטופולוגיה הרגילה עליו (טופולוגיה שאנחנו כבר יודעים לקבל בעזרת מטריקות ובעזרת טופולוגיית הסדר) ומסתכלים על הטופולוגיה של המכפלה {% equation %}\mathbb{R}^{n}{% endequation %} שמתקבלת ממה שתיארנו כאן? באופן לא מפתיע, מקבלים את הטופולוגיה ה"רגילה" על {% equation %}\mathbb{R}^{n}{% endequation %}, זו שמתקבלת מהמטריקה האוקלידית. אז אין לנו הזיות כמו מה שקרה קודם עם טופולוגיית תת-המרחב שבו הבניה החדשה שלנו התנגשה חזיתית עם בניות קודמות. בינתיים.

יש עוד דרך מועילה מאוד במתמטיקה באופן כללי להסתכל על מכפלות - להסתכל על **הטלות**. אם יש לנו מרחב מכפלה {% equation %}X\times Y{% endequation %} אז אנחנו מגדירים הטלות ברכיב הראשון והשני על ידי

- {% equation %}\pi_{1}:X\times Y\to X{% endequation %} כך ש-{% equation %}\pi_{1}\left(x,y\right)=x{% endequation %} 

- {% equation %}\pi_{2}:X\times Y\to Y{% endequation %} כך ש-{% equation %}\pi_{2}\left(x,y\right)=y{% endequation %} 

את זה מן הסתם קל להכליל גם למכפלה של מספר סופי כלשהו של מוכפלים:

- {% equation %}\pi_{i}:X_{1}\times X_{2}\times\ldots\times X_{n}\to X_{i}{% endequation %} כך ש-{% equation %}\pi_{i}\left(x_{1},\ldots,x_{n}\right)=x_{i}{% endequation %} 

עכשיו, נניח שעדיין אין לנו טופולוגיה על {% equation %}X\times Y{% endequation %}, אבל יש לנו יעד קונקרטי - אנחנו רוצים שההטלות מהמכפלה הזו יהיו **פונקציות רציפות**. כלומר, אני רוצה ש-{% equation %}\pi^{-1}_{1}\left(U\right){% endequation %} תהיה קבוצה פתוחה ב-{% equation %}X\times Y{% endequation %} לכל {% equation %}U\subseteq X{% endequation %} פתוחה, ובדומה גם עבור {% equation %}\pi_{2}{% endequation %} . עכשיו, מה זו {% equation %}\pi^{-1}_{1}\left(U\right){% endequation %} ? קל לבדוק ש-{% equation %}\pi^{-1}_{1}\left(U\right)=U\times Y{% endequation %}, אז אני רוצה שכל הקבוצות מהצורה הזו יהיו פתוחות. בדומה אני רוצה שכל הקבוצות מהצורה {% equation %}X\times V{% endequation %}, כאשר {% equation %}V{% endequation %} פתוחה ב-{% equation %}Y{% endequation %}, יהיו פתוחות. הגדרה כזו, של "הנה אוסף קבוצות שאני רוצה שיהיו פתוחות, תנו לי את הטופולוגיה המינימלית שמקיימת את זה" היא פשוט הגדרה של טופולוגיה בעזרת **תת-בסיס**. הדרישה היחידה מתת-בסיס הוא שכל איבר במרחב יהיה שייך אל איבר כלשהו ממנו מה שמן הסתם מתקיים עבור {% equation %}\pi^{-1}_{1}\left(X\right)=X\times Y{% endequation %} . עכשיו, מכיוון שכל האיברים {% equation %}U\times Y{% endequation %} ו-{% equation %}X\times V{% endequation %} כבר היו שייכים לבסיס שתיארתי קודם, והחיתוך של שני איברים כאלו הוא משהו מהצורה {% equation %}U\times V{% endequation %}, אני מקבל מההגדרה הזו **בדיוק** את אותה טופולוגיה כמו קודם. פשוט מאוד לבינתיים!

אוקיי, אז בואו נסבך את זה עם האופן שבו מתמטיקאים אוהבים לסבך דברים: בואו נכניס לתמונה את **אינסוף**.

## טופולוגיית המכפלה - החלק האינסופי

האופן שבו הגדרתי מכפלה קרטזית, עם זוגות סדורים ואז "בואו נעשה את זה שוב" לא מביא אותנו יותר מדי רחוק, פורמלית. אפילו הקטע של ה"בואו נעשה את זה שוב". הוא בעייתי. [יש לי פוסט על זה](https://gadial.net/2020/06/20/general_cartesian_products/), אז כאן אני אסתפק בשורה התחתונה: אם רוצים להגדיר מכפלה קרטזית של יותר משתי קבוצות, הדרך הנכונה לעשות את זה היא באמצעות **פונקציות** (ופונקציות, בתורן, הן מושג שמסתמך על מכפלה קרטזית של שתי קבוצות אז גם למושג הזה אנחנו זקוקים). פורמלית, נניח שיש לנו קבוצת **אינדקסים**{% equation %}\Lambda{% endequation %} כך שלכל {% equation %}\alpha\in\Lambda{% endequation %} מתאימה קבוצה {% equation %}X_{\alpha}{% endequation %} . אז **המכפלה הקרטזית** של הקבוצות הללו, שמסומנת {% equation %}\prod_{\alpha\in\Lambda}X_{\alpha}{% endequation %} היא אוסף כל הפונקציות {% equation %}a:\Lambda\to\bigcup_{\alpha\in\Lambda}X_{\alpha}{% endequation %} כך ש-{% equation %}a\left(\alpha\right)\in X_{\alpha}{% endequation %} לכל {% equation %}\alpha\in\Lambda{% endequation %} . הרעיון הוא ש-{% equation %}\Lambda{% endequation %} מייצגת את ה**קואורדינטות** של המכפלה ו-{% equation %}a{% endequation %} היא מה שאומר לנו, לכל קואורדינטה, איזה ערך ספציפית נמצא בה - תחת הדרישה שהערך בקואורדינטה שמאונדקסת על ידי {% equation %}\alpha{% endequation %} שייך לקבוצה {% equation %}X_{\alpha}{% endequation %} . זה מכליל את מה שראינו קודם: המקרה של {% equation %}X_{1}\times\ldots\times X_{n}{% endequation %} הוא פשוט מה שמקבלים עבור {% equation %}\Lambda=\left\{ 1,2,\ldots,n\right\}{% endequation %}, אבל אפשר לקחת את זה הרבה יותר רחוק - לקבוצות אינדקסים אינסופיות, ואפילו לא בנות מניה.

הדוגמא האינסופית הפשוטה ביותר היא {% equation %}X_{1}\times X_{2}\times X_{3}\times\ldots{% endequation %} שמתאימה למקרה של {% equation %}\Lambda=\mathbb{N}{% endequation %} (בגרסה של {% equation %}\mathbb{N}{% endequation %} שלא כוללת את 0). למשל, אם ניקח {% equation %}X_{1}=X_{2}=X_{3}=\ldots=\mathbb{R}{% endequation %} אז למכפלה שמקבלים קוראים {% equation %}\mathbb{R}^{\omega}{% endequation %} (פורמלית, {% equation %}\omega=\left\{ 0,1,2,\ldots\right\}{% endequation %} אבל נעזוב את זה). עוד נשתמש במרחב הזה אבל אותי יותר מעניין להראות דוגמא פחות מובנת מאליה במבט ראשון: בואו ניקח את {% equation %}\mathbb{R}{% endequation %} ונכפול אותו בעצמו מספר לא בן מניה של פעמים, עם קבוצת האינדקסים {% equation %}\Lambda=\mathbb{R}{% endequation %} . מה מקבלים? ובכן, מקבלים את כל הפונקציות מ-{% equation %}\mathbb{R}{% endequation %} (זו קבוצת האינדקסים) אל {% equation %}\mathbb{R}{% endequation %} (זה האיחוד של כל העותקים של {% equation %}\mathbb{R}{% endequation %} שאנחנו מכפילים) כך שלכל {% equation %}r\in\mathbb{R}{% endequation %} מתקיים {% equation %}a\left(r\right)\in\mathbb{R}{% endequation %} (כלומר, במקרה הזה הדרישה על שייכות ל-{% equation %}X_{\alpha}{% endequation %} היא טריוויאלית כי כל המוכפלים זהים). כלומר, קיבלנו... פונקציות רגילות על {% equation %}\mathbb{R}{% endequation %} ? את הקבוצה {% equation %}\mathbb{R}^{\mathbb{R}}{% endequation %} ? אלו הפונקציות שמככבות בחשבון אינפיניטסימלי 1, נקודת המוצא שלנו לכל המהומה הנוכחית, ואפשר לחשוב עליהן גם בתור איברים של מכפלה קרטזית של {% equation %}\mathbb{R}{% endequation %} בעצמו מספיק פעמים.

יפה, אז אנחנו מבינים איך להגדיר מכפלה קרטזית כללית. עכשיו, בהינתן מכפלה כזו {% equation %}\prod_{\alpha\in\Lambda}X_{\alpha}{% endequation %} , איך נגדיר עליה טופולוגיה? בחלק הקודם הצגתי שתי גישות שנתנו את אותה התוצאה:

1. לקחת בתור בסיס לטופולוגיה את כל הקבוצות שהן מכפלות של קבוצות פתוחות. כלומר, כל הקבוצות מהצורה {% equation %}\prod_{\alpha\in\Lambda}U_{\alpha}{% endequation %} כך ש-{% equation %}U_{\alpha}\subseteq X_{\alpha}{% endequation %} פתוחה.

2. לקחת בתור תת-בסיס לטופולוגיה את כל הקבוצות שהן מקורות של פונקציות ההטלה. כלומר, כל הקבוצות מהצורה {% equation %}\pi^{-1}_{\alpha}\left(U_{\alpha}\right){% endequation %} כך ש-{% equation %}U_{\alpha}\subseteq X_{\alpha}{% endequation %} פתוחה.

רק כדי ליישר קו, הטלה מוגדרת כמו קודם: אם {% equation %}a\in\prod_{\alpha\in\Lambda}X_{\alpha}{% endequation %} הוא איבר במכפלה הקרטזית, אז {% equation %}\pi_{\alpha}\left(f\right)=a\left(\alpha\right){% endequation %} . אז אני מקווה ששתי ההגדרות ברורות - והנה העניין, **הן לא נותנות את אותה טופולוגיה**.

1. ההגדרה הראשונה נותנת את מה שנקרא **טופולוגיית התיבה** (Box Topology)

2. ההגדרה השניה נותנת את מה שנקרא **טופולוגיית המכפלה** (Product Topology)

מה ההבדל? ובכן, בואו נראה מה קורה בטופולוגיית המכפלה. כל איבר של תת-הבסיס שלנו הוא מהצורה {% equation %}\pi^{-1}_{\alpha}\left(U_{\alpha}\right){% endequation %} . אינטואיטיבית מה שזה אומר הוא שהמקור הזה הוא מכפלה של **כל** המרחב עבור **כל** הקואורדינטות, חוץ מאשר עבור הקואורדינטה ה-{% equation %}\alpha{% endequation %} ושם מי שמוכפל הוא {% equation %}U_{\alpha}{% endequation %} . למשל, עבור המכפלה {% equation %}X_{1}\times X_{2}\times X_{3}\times\ldots{% endequation %} אנחנו נקבל ש-

{% equation %}\pi^{-1}_{2}\left(U\right)=X_{1}\times U\times X_{3}\times\ldots{% endequation %} כלומר, אנחנו לוקחים את כל המרחב ו**מגבילים** רק קואורדינטה אחת. לעומת זאת, בטופולוגיית התיבה אנחנו יכולים להגביל את כל אינסוף הקואורדינטות **בו זמנית**.

עכשיו, בהגדרה השניה הגדרנו **תת-בסיס**. זה אומר שעדיין אפשר לקחת חיתוכים של האיברים הללו. כשאנחנו חותכים שני איברים כאלו אנחנו נקבל הגבלה על **שתי** קואורדינטות, ובאופן כללי חיתוך סופי של איברים כאלו יתן לנו הגבלה על **מספר סופי** של קואורדינטות; אבל בטופולוגיית התיבה אפשר להגביל גם **מספר אינסופי** של קואורדינטות. זה ההבדל בין שתי ההגדרות, ועכשיו גם ברור למה במקרה הסופי הוא לא בא לידי ביטוי בכלל.

לאלו מכן שמכירות אלגברה זה אולי מזכיר את ההבדל בין** מכפלה ישרה** ובין **סכום ישר** של מבנים אלגבריים; מכפלה ישרה זו פשוט מכפלה קרטזית רגילה שיורשת את המבנה האלגברי שלה מהאיברים שמשתתפים במכפלה, אבל **סכום ישר** כולל רק את האיברים של המכפלה הישרה שהם 0 בכל כניסה חוץ ממספר סופי של כניסות. עוד מקרה שבו ההבדל הזה נפוץ ומוכר הוא ההבדל שבין **פולינומים** ובין **טורי חזקות**; אפשר לחשוב על פולינום בתור טור חזקות שבו כל המקדמים הם 0 החל ממקום מסוים. בקיצור, הרעיון הזה הוא לא כזה חדש ומפתיע - אבל במבט ראשון זה כן מוזר שיש פה הבדל, ועוד יותר לא ברור למה להעדיף דווקא את ההגדרה השניה, הרי הראשונה מרגישה טבעית יותר. הנימוק הוא כמובן "חכו ותראו, משפט טיכונוף לא עובד בטופולוגיית התיבה!!!!!" (ההגדרה של טופולוגיית המכפלה ליטרלי הגיעה מהמאמר של טיכונוף שבו הוא הוכיח את משפט טיכונוף) אבל מכיוון שאין לנו מושג כרגע מה זה משפט טיכונוף אולי כדאי לנסות לתת הסבר קונקרטי יותר כבר עכשיו.

ראשית, מה ההבדל בין הטופולוגיות? אפשר להציג את שניהן באמצעות בסיסים. בטופולוגיית התיבה, כל איבר בסיס הוא מהצורה {% equation %}\prod_{\alpha\in\Lambda}U_{\alpha}{% endequation %} כך ש-{% equation %}U_{\alpha}\subseteq X_{\alpha}{% endequation %} פתוחה. בטופולוגיית המכפלה, כל איבר בסיס הוא מהצורה {% equation %}\prod_{\alpha\in\Lambda}U_{\alpha}{% endequation %} כך ש-{% equation %}U_{\alpha}\subseteq X_{\alpha}{% endequation %} פתוחה ובנוסף לכך מתקיים {% equation %}U_{\alpha}=X_{\alpha}{% endequation %} לכל {% equation %}\alpha\in\Lambda{% endequation %} פרט אולי למספר סופי. מה שברור מייד מלהציג את זה ככה הוא שכל קבוצה שפתוח בטופולוגיית המכפלה פתוחה גם בטופולוגיית התיבה. אינטואיטיבית אולי היינו משתמשים במילים יפות כמו "טופולוגיית התיבה **עשירה יותר** מטופולוגיית המכפלה" או "טופולוגיית התיבה **עדינה יותר **מטופולוגיית המכפלה" אבל אני גם לא סובל את השמות הללו וגם לפעמים משתמשים בהם במשמעות ההפוכה. עדיין, לא ברור למה טופולוגיית המכפלה עדיפה - האם לא עדיפה טופולוגיית התיבה, שבה יש יותר קבוצות פתוחות? יותר קבוצות פתוחות, חיים יותר מעניינים, לא?

אז ראשית, זה לא שיש טופולוגיה טובה וטופולוגיה רעה. לכל אחת מהן יש שימושים. פשוט אחת מהן הרבה יותר שימושית מהאחרת. אז בואו נדגים משפט שנראה "טבעי" ואפשר להוכיח אותו בטופולוגיית המכפלה אבל אי אפשר להוכיח בטופולוגיית התיבה, ודווקא מקבלים אינטואיציה טובה למה "עוד קבוצות פתוחות" זה לאו דווקא דבר טוב.

העניין הוא כזה: איך אפשר לבנות פונקציה רציפה **שהטווח** שלה הוא מכפלה קרטזית? למשל, {% equation %}f:\mathbb{R}\to\mathbb{R}^{2}{% endequation %} ? תוצאה בסיסית בחשבון אינפיניטסימלי אומרת שכדאי להסתכל על **הרכיבים** של הפונקציה - להציג אותה בתור {% equation %}f\left(x\right)=\left(f_{1}\left(x\right),f_{2}\left(x\right)\right){% endequation %} כך ש-{% equation %}f_{1},f_{2}:\mathbb{R}\to\mathbb{R}{% endequation %}, ואם כל אחת מהפונקציות הללו היא רציפה בעצמה, אז {% equation %}f{% endequation %} המקורית רציפה. בואו נוכיח את זה גם למקרה שבו יש לנו מכפלה קרטזית אינסופית. כלומר נתונן לנו מרחב טופולוגי {% equation %}X{% endequation %} כלשהו ומשפחה {% equation %}Y_{\alpha}{% endequation %} של מרחבים ואנחנו מסתכלים על פונקציה {% equation %}f:X\to\prod_{\alpha\in\Lambda}Y_{\alpha}{% endequation %} . את הפונקציה הזו נתאר על ידי רכיבים, כך ש-{% equation %}f_{\beta}:X\to Y_{\beta}{% endequation %} הוא הרכיב שמתאים ל-{% equation %}\beta{% endequation %} . פורמלית, {% equation %}f_{\beta}=\pi_{\beta}f{% endequation %} - ההרכבה של ההטלה על הרכיב {% equation %}\beta{% endequation %} שמורכבת על הפונקציה {% equation %}f{% endequation %} . שימו לב שאם {% equation %}f{% endequation %} רציפה ואנחנו מעל טופולוגיית המכפלה ולכן גם {% equation %}\pi_{\beta}{% endequation %}, אז נקבל מייד ש-{% equation %}f_{\beta}{% endequation %} רציפה כי היא הרכבה של שתי פונקציות רציפות והראיתי בפוסט הקודם שהרכבה כזו היא רציפה. החלק המעניין הוא הכיוון השני - נניח שכל הרכיבים הללו רציפים ונוכיח ש-{% equation %}f{% endequation %} רציפה.

בשביל להראות ש-{% equation %}f{% endequation %} היא רציפה, ניקח קבוצה פתוחה ב-{% equation %}\prod_{\alpha\in\Lambda}Y_{\alpha}{% endequation %} ונראה שהמקור שלה גם פתוח. הנה מייד ברור מה היתרון בטופולוגיית המכפלה - אנחנו צריכים לטפל רק בקבוצות **פשוטות יחסית**. בטופולוגיית התיבה האתגר שלנו יהיה גדול בהרבה דווקא בגלל שיש יותר קבוצות פתוחות. עכשיו, בפוסט הקודם הראיתי שלא צריך לטפל **בכל** קבוצה פתוחה; אם יש למרחב שלנו תת-בסיס {% equation %}\mathcal{B}{% endequation %}, מספיק להראות שלכל {% equation %}B\in\mathcal{B}{% endequation %}, {% equation %}f^{-1}\left(B\right){% endequation %} היא קבוצה פתוחה. עכשיו, בטופולוגיית המכפלה תת-הבסיס שלנו מורכב מקבוצות מהצורה {% equation %}\pi^{-1}_{\beta}\left(U\right){% endequation %} כש-{% equation %}U\subseteq Y_{\beta}{% endequation %} היא קבוצה פתוחה. עכשיו, עוד דבר שראינו בפוסט הקודם הוא שמתקיים באופן כללי, עבור פונקציות {% equation %}f:A\to B{% endequation %} ו-{% equation %}g:B\to C{% endequation %} ו-{% equation %}D\subseteq C{% endequation %} :

{% equation %}\left(gf\right)^{-1}\left(D\right)=f^{-1}\left(g^{-1}\left(D\right)\right){% endequation %} אצלנו {% equation %}g{% endequation %} היא הפונקציה {% equation %}\pi_{\beta}:\prod_{\alpha\in\Lambda}Y_{\alpha}\to Y_{\beta}{% endequation %} . מה ההרכבה {% equation %}\pi_{\beta}f{% endequation %} ? כאמור, זו בדיוק פונקציית הרכיב {% equation %}f_{\beta}{% endequation %} שהנחתי שהיא רציפה, ומכאן ש-{% equation %}f^{-1}_{\beta}\left(U\right){% endequation %} קבוצה פתוחה, ולכן {% equation %}f^{-1}\left(\pi^{-1}_{\beta}\left(U\right)\right)=f^{-1}_{\beta}\left(U\right){% endequation %} היא קבוצה פתוחה וזה בדיוק מה שרצינו להראות - שהמקור על פי {% equation %}f{% endequation %} של איבר תת-הבסיס {% equation %}\pi^{-1}_{\beta}\left(U\right){% endequation %} הוא קבוצה פתוחה. זה מסיים את ההוכחה הזו.

ההוכחה הזו אולי נתנה לנו אינטואיציה לקושי הנוסף שטופולוגיית התיבה מציבה בפנינו, אבל זה לכשעצמו לא **מוכיח** שהטענה פשוט לא עובדת עבור טופולוגיית התיבה. צריך לתת דוגמא מפורשת, והדוגמא הזו תצטרך מן הסתם להיות מכפלה אינסופית (אחרת שתי הטופולוגיות שקולות). אז בואו ניקח את המקרה הפשוט של {% equation %}\mathbb{R}^{\omega}{% endequation %} שבו {% equation %}\mathbb{R}{% endequation %} מוכפל בעצמו מספר בן מניה של פעמים. עכשיו, את מי ניקח בתור דוגמא לפונקציה שהרכיבים שלה רציפים אבל היא עצמה לא רציפה? ובכן, זוכרים שקודם השתמשתי ב-{% equation %}\left\{ \left(a,a\right)\ |\ a\in A\right\}{% endequation %} בתור דוגמא לתת-קבוצה של מכפלה שאי אפשר "לפרק למכפלה"? נעשה משהו דומה אבל עם פונקציה - נגדיר

{% equation %}f:\mathbb{R}\to\mathbb{R}^{\omega}{% endequation %} על ידי

{% equation %}f\left(x\right)=\left(x,x,x,\ldots\right){% endequation %}

 כל רכיב כאן הוא פונקציית הזהות {% equation %}f_{i}\left(x\right)=x{% endequation %} שהיא בוודאי רציפה על {% equation %}\mathbb{R}{% endequation %} . אז למה {% equation %}f{% endequation %} לא רציפה בטופולוגיית התיבה? אני חושב שקל להבין את זה אם מסתכלים רגע באופן נקדותי על הפונקציה בנקודה כלשהית וספציפית נוח להסתכל ב-0 בגלל הסימטריה. אם {% equation %}f{% endequation %} רציפה ב-0 זה אומר שלכל קבוצה פתוחה {% equation %}V\subseteq\mathbb{R}^{\omega}{% endequation %} שמכילה את {% equation %}\left(0,0,0,\ldots\right){% endequation %}, קיימת קבוצה פתוחה {% equation %}U\subseteq\mathbb{R}{% endequation %} שמכילה את 0 כך ש-{% equation %}f\left(x\right)\in V{% endequation %} לכל {% equation %}x\in U{% endequation %}, כלומר {% equation %}\left(x,x,x,\ldots\right)\in V{% endequation %} לכל {% equation %}x\in U{% endequation %} . בזכות העובדה ש-{% equation %}U{% endequation %} פתוחה ב-{% equation %}\mathbb{R}{% endequation %}, יש בה {% equation %}x\ne0{% endequation %} כלשהו, ולכן אנחנו מצטמצמים לשאלה הבאה: האם נוכל להטריל את נסיון ההוכחה הזה על ידי כך שנמצא קבוצה {% equation %}V{% endequation %} שמכילה את {% equation %}\left(0,0,0,\ldots\right){% endequation %} אבל לא מכילה **שום איבר אחר** מהצורה {% equation %}\left(x,x,x,\ldots\right){% endequation %} ? והתשובה היא "כן, בקלות" כי פשוט צריך לבנות את {% equation %}V{% endequation %} בתור אוסף של קטעים פתוחים סביב 0 שהולכים ומצטמצמים. פורמלית:

{% equation %}V=\left(-1,1\right)\times\left(-\frac{1}{2},\frac{1}{2}\right)\times\left(-\frac{1}{3},\frac{1}{3}\right)\times\dots\times\left(-\frac{1}{n},\frac{1}{n}\right)\times\dots{% endequation %} 

הסיבה שאנחנו מסוגלים לבנות דבר כזה היא שטופולוגיית התיבה נותנת לנו לשלוט על כל אינסוף הרכיבים במכפלה הזו. בטופולוגיית התיבה זה בלתי אפשרי - אחרי מספר סופי של רכיבים נצטרך להתייאש וכל יתר הרכיבים יהיו פשוט {% equation %}\mathbb{R}{% endequation %} ונסיון ההטרלה ייכשל.

לסיום, בואו נראה עוד דרך להסתכל על זה, הפעם עבור המרחב {% equation %}\mathbb{R}^{\mathbb{R}}{% endequation %} שהוא כזכור מצד אחד פשוט אוסף הפונקציות הממשיות ומצד שני אנחנו רואים אותו בתור מרחב מכפלה עם טופולוגיה עליו. מה זו קבוצה פתוחה במרחב הזה? בטופולוגיית המכפלה, קבוצת תת-בסיס היא {% equation %}\mathbb{R}{% endequation %} בכל הקואורדינטות חוץ מאחת, שבה היא {% equation %}U{% endequation %} עבור קבוצה פתוחה {% equation %}U\subseteq\mathbb{R}{% endequation %} . נאמר שזה בקואורדינטה {% equation %}a{% endequation %} . אז {% equation %}f\in\mathbb{R}^{\mathbb{R}}{% endequation %} שייכת לאיבר תת-הבסיס הזה אם היא מקיימת {% equation %}f\left(a\right)\in U{% endequation %} . כלומר, השייכות לקבוצה הפתוחה הזו מתורגמת לאילוץ **נקודתי**: הערך של {% equation %}f{% endequation %} בנקודה ספציפית לא יכול להיקבע בחופשיות אלא הוא שייך ל-{% equation %}U{% endequation %} . אם נחשוב על {% equation %}U{% endequation %} בתור אוסף של קטעים פתוחים, אז נוח לי לדמיין את הקבוצה הפתוחה בתור מעין "מחסום" אנכי שהוא הישר {% equation %}x=a{% endequation %}, ובתוך המחסום הזה יש "שערים" שדרכם הפונקציה יכולה לעבור ומתאימים לקטעים הפתוחים ב-{% equation %}U{% endequation %} . 

כשלוקחים אברי תת-בסיס כזה וחותכים אותם, זה כאילו מוספים עוד מספר סופי של מחסומים עם שערים שכאלו. ובטופולוגיית התיבה יכולים להיות מחסומים **בכל מקום**, מה שמאפשר לנו להגביל מאוד את הפונקציות שיכולות להיכנס לקבוצות הפתוחות שאנחנו בונים.

מעניין לראות איך זה בא לידי ביטוי בהקשר של **התכנסות**. המרחב שלנו הוא מרחב של פונקציות ממשיות, אז כשאני מדבר על התכנסות אני מדבר על לקחת סדרה של פונקציות ולבדוק לאיזו **פונקציה** היא מתכנסת. זה משהו [שכבר דיברתי עליו בבלוג](https://gadial.net/2024/02/24/sequences_and_series_of_functions/), ואמרתי אז שיש שני סוגי התכנסות שמעניינים אותנו בהקשר הזה; שתי דרכים לומר שהסדרה {% equation %}f_{n}{% endequation %} של פונקציות ממשיות מתכנסת אל הפונקציה {% equation %}f{% endequation %} :

- {% equation %}f_{n}{% endequation %} מתכנסת **נקודתית** אל {% equation %}f{% endequation %} אם לכל {% equation %}x\in\mathbb{R}{% endequation %}, לכל {% equation %}\varepsilon\gt 0{% endequation %} קיים {% equation %}N{% endequation %} טבעי כך שלכל {% equation %}n\gt N{% endequation %} מתקיים {% equation %}\left|f_{n}\left(x\right)-f\left(x\right)\right|\lt \varepsilon{% endequation %} .

- {% equation %}f_{n}{% endequation %} מתכנסת **במידה שווה** אל {% equation %}f{% endequation %} אם לכל {% equation %}\varepsilon\gt 0{% endequation %} קיים {% equation %}N{% endequation %} טבעי כך שלכל {% equation %}n\gt N{% endequation %} מתקיים {% equation %}\left|f_{n}\left(x\right)-f\left(x\right)\right|\lt \varepsilon{% endequation %} לכל {% equation %}x\in\mathbb{R}{% endequation %} .

המשמעות של התכנסות בטופולוגיית המכפלה היא התכנסות **נקודתית**. למה? כי אם {% equation %}f_{n}\to f{% endequation %} בטופולוגיית המכפלה, אז לכל סביבה של {% equation %}f{% endequation %} קיים {% equation %}N{% endequation %} כך שלכל {% equation %}n\gt N{% endequation %} גם {% equation %}f_{n}{% endequation %} שייך לאותה סביבה. עכשיו, נניח שאני רוצה להראות ש-{% equation %}f_{n}{% endequation %} מתכנסת נקודתית, אז ניקח נקודה {% equation %}x\in\mathbb{R}{% endequation %} ו-{% equation %}\varepsilon\gt 0{% endequation %} ועכשיו ניקח את הסביבה שהיא איבר תת-בסיס שהוא {% equation %}\mathbb{R}{% endequation %} בכל קואורדינטה למעט זו של {% equation %}x{% endequation %} שבה יש את {% equation %}\left(f\left(x\right)-\varepsilon,f\left(x\right)+\varepsilon\right){% endequation %} . אז קיים {% equation %}N{% endequation %} כך שלכל {% equation %}n\gt N{% endequation %} מתקים {% equation %}f_{n}\left(x\right)\in\left(f\left(x\right)-\varepsilon,f\left(x\right)+\varepsilon\right){% endequation %} שזו דרך אחרת לומר {% equation %}\left|f_{n}\left(x\right)-f\left(x\right)\right|\lt \varepsilon{% endequation %} .

בכיוון השני, אם {% equation %}f_{n}\to f{% endequation %} נקודתית זה מספיק כדי להבטיח התכנסות בטופולוגיית המכפלה. אם לוקחים סביבה של {% equation %}f{% endequation %}, אז יש איבר בסיס שמכיל את {% equation %}f{% endequation %} ומוכל בסביבה הזו. איבר הבסיס הזה יכול לכלול הגבלות לא רק על קואורדינטה אחת אלא על מספר **סופי** של קואורדינטות, אבל יש טריק סטנדרטי של אינפי להתמודד עם זה. לכל קואורדינטה יש את ה-{% equation %}N_{x}{% endequation %} משלה, על פי ההתכנסות הנקודתית; פשוט נבחר את {% equation %}N=\max_{x}\left\{ N_{x}\right\}{% endequation %} להיות המקסימום על כל ה-{% equation %}N_{x}{% endequation %} -ים הללו. המקסימום קיים כי יש רק מספר **סופי** של {% equation %}N_{x}{% endequation %} -ים שכאלו.

כל זה כמובן לא יכול לעבוד בטופולוגיית התיבה. זה השלב שבו היה מאוד נחמד אם הייתי אומר שמה שטופולוגיית התיבה נותנת לנו הוא התכנסות במידה שווה - אבל לא, היא לא נותנת אפילו את זה. גם התכנסות במידה שווה היא חלשה מדי מכדי להבטיח התכנסות בטופולוגיית התיבה (יש טופולוגיה אחרת, uniform topology, שבאה לתת התכנסות במידה שווה, אבל לא נדבר עליה כאן).

למה זה לא עובד אפילו עם התכנסות במידה שווה? ובכן, אותו טריק של

{% equation %}V=\left(-1,1\right)\times\left(-\frac{1}{2},\frac{1}{2}\right)\times\left(-\frac{1}{3},\frac{1}{3}\right)\times\dots\times\left(-\frac{1}{n},\frac{1}{n}\right)\times\dots{% endequation %} 

שראינו קודם יעבוד גם כאן. פשוט במקום עכשיו שזו תהיה **כל**{% equation %}V{% endequation %}, זו תהיה {% equation %}V{% endequation %} רק בכניסות שהם מספרים טבעיים. כלומר, אנחנו נדרוש ש-{% equation %}f_{n}{% endequation %}, בקואורדינטה {% equation %}k{% endequation %} עבור {% equation %}k{% endequation %} טבעי, תהיה קרובה אל {% equation %}f{% endequation %} עד כדי {% equation %}\frac{1}{k}{% endequation %} ({% equation %}\left|f_{n}\left(k\right)-f\left(k\right)\right|\lt \frac{1}{k}{% endequation %} ). התכנסות במידה שווה לא יכולה לתת את זה - היא צריכה {% equation %}\varepsilon{% endequation %} קונקרטי שיעבוד בו זמנית לכל הקואורדינטות, אבל כאן צריך שככל שהאינדקס של הקואורדינטה גדל, כך ה-{% equation %}\varepsilon{% endequation %} הרלוונטי אליה יהיה יותר ויותר קטן. במילים אחרות, צריך שהוא יהיה {% equation %}\varepsilon\left(x\right){% endequation %} , כזה שתלוי ב-{% equation %}x{% endequation %} ויכול לקטון כרצוננו. אפשר לנסח התכנסות כזו, אבל אני חושב שכבר ברור איך טופולוגיית התיבה מסבכת לנו את החיים ולמה בדרך כלל נעדיף להשתמש בטופולוגיית המכפלה.
