לפני שנגיע לדבר העיקרי שאני רוצה לדבר עליו, **פונקציות רציפות**, בואו נפתח עם חימום שמשלים חוב שיש לי.

בפוסט הקודם ראינו את ההגדרה הבסיסית של מרחב טופולוגי. בואו ניזכר בה:

**מרחב טופולוגי** הוא זוג {% equation %}\left(X,\mathcal{T}\right){% endequation %} של קבוצה {% equation %}X{% endequation %} ו-{% equation %}\mathcal{T}\subseteq\mathcal{P}\left(X\right){% endequation %} הוא אוסף של תת-קבוצות של {% equation %}X{% endequation %} שאנחנו קוראים להן **קבוצות פתוחות**. הדרישה מ-{% equation %}\mathcal{T}{% endequation %} היא שיתקיימו שלוש התכונות הבאות:

- {% equation %}\emptyset,X\in\mathcal{T}{% endequation %} 

- אם יש לנו אוסף קבוצות {% equation %}A_{i}\in\mathcal{T}{% endequation %} אז {% equation %}\bigcup_{i}A_{i}\in\mathcal{T}{% endequation %} 

- אם יש לנו מספר סופי של קבוצות {% equation %}A_{1},\ldots,A_{n}\in\mathcal{T}{% endequation %} אז {% equation %}\bigcap^{n}_{i=1}A_{i}\in\mathcal{T}{% endequation %} 

עכשיו, בפוסטים הקודמים ראינו כמה מושגים קשורים, למשל **קבוצות סגורות**. אחת מהתוצאות שראינו עבור מרחבים מטריים הייתה שהמשלימה של קבוצה סגורה היא פתוחה, וההפך. לכן מתבקש להפוך את זה להגדרה במקרה שלנו: **קבוצה סגורה** היא קבוצה שהמשלימה שלה פתוחה. אבל איך זה מתקשר לאופן שבו הגדרנו פעם קבוצה סגורה? בואו נזמן לרגע את רשימת ה"מה עשינו פה" מהפוסט של הקבוצות הסגורות:

- בהינתן {% equation %}X{% endequation %} כלשהי, לקחנו {% equation %}\mathcal{T}\subseteq\mathcal{P}\left(X\right){% endequation %} וקראנו לאיברים שלה **קבוצות פתוחות**.

- לכל {% equation %}x\in X{% endequation %}, קראנו בשם **סביבה** של {% equation %}x{% endequation %} לקבוצה פתוחה {% equation %}U\in\mathcal{T}{% endequation %} כלשהי כך ש-{% equation %}x\in U{% endequation %} .

- הגדרנו **נקודת הצטברות** של קבוצה {% equation %}A{% endequation %} בתור נקודה {% equation %}x{% endequation %} שכל סביבה שלה כוללת איבר של {% equation %}A{% endequation %} ששונה מ-{% equation %}x{% endequation %} .

- הגדרנו **קבוצה סגורה** בתור קבוצה שכוללת את כל נקודות ההצטברות שלה.

אחר כך הראינו **במרחבים מטריים** את השקילות של ההגדרה הזו של קבוצה סגורה וההגדרה של "המשלימה שלה פתוחה". אבל אנחנו יכולים לעשות את זה באופן כללי, עם האקסיומות של מרחבים טופולוגיים. וכדי לעשות את זה בצורה נחמדה שתלמד אותנו משהו חדש, אפשר להכניס לתמונה מושגים חדשים שההגדרה שלהם בשפה טופולוגית היא טבעית למדי - **הסגור** (Closure) וה**פנים** (Interior) של קבוצה.

- הסגור של קבוצה {% equation %}A{% endequation %} שמסומן {% equation %}\overline{A}{% endequation %} הוא חיתוך כל הקבוצות הסגורות שמכילות את {% equation %}A{% endequation %} (מכיוון ש-{% equation %}X{% endequation %} היא סגורה כי המשלימה שלה היא {% equation %}\emptyset{% endequation %} הפתוחה, אז החיתוך הזה לא נלקח על אוסף ריק של קבוצות, שזה כידוע דבר שאי אפשר לעשות). כלומר, {% equation %}\overline{A}{% endequation %} היא הקבוצה הסגורה **המינימלית** שמכילה את {% equation %}A{% endequation %} .

- הפנים של קבוצה {% equation %}A{% endequation %} שמסומן {% equation %}\text{int}A{% endequation %} הוא איחוד כל הקבוצות הפתוחות שמוכלות ב-{% equation %}A{% endequation %} . כלומר, {% equation %}\text{int}A{% endequation %} היא הקבוצה הפתוחה **המקסימלית** שמוכלת ב-{% equation %}A{% endequation %} .

מה זה אומר, בעצם? על פי הגדרה, {% equation %}\text{int}A\subseteq A\subseteq\overline{A}{% endequation %} (כי כשמאחדים קבוצות שכולן מוכלות ב-{% equation %}A{% endequation %} גם התוצאה מוכלת ב-{% equation %}A{% endequation %}, וכנ"ל כשחותכים קבוצות שכולן מכילות את כל {% equation %}A{% endequation %} ). אז הרעיון הוא שכשעוברים מ-{% equation %}A{% endequation %} אל {% equation %}\overline{A}{% endequation %} מוסיפים לה נקודות וכשעוברים אל {% equation %}\text{int}A{% endequation %} מורידים ממנה נקודות, אבל איזה נקודות? אינטואיטיבית, נקודות השפה של {% equation %}A{% endequation %}, מה שקראנו לו {% equation %}\partial A{% endequation %} - כל הנקודות שבכל סביבה שלהן יש איבר מ-{% equation %}A{% endequation %} ואיבר מ-{% equation %}A^{c}{% endequation %}, המשלימה של {% equation %}A{% endequation %} .

בואו נראה את זה פורמלית. ראשית אני אוכיח ש-{% equation %}\overline{A}=A\cup\partial A{% endequation %} . בואו נתחיל עם נקודה {% equation %}x\in\partial A{% endequation %} ונוכיח שהיא ב-{% equation %}\overline{A}{% endequation %} . בשביל זה מספיק להראות שלכל קבוצה סגורה {% equation %}D{% endequation %} כך ש-{% equation %}A\subseteq D{% endequation %}, {% equation %}x\in D{% endequation %} . נניח בשלילה שזה לא המצב, כלומר {% equation %}x\notin D{% endequation %}, כלומר {% equation %}x\in D^{c}\subseteq A^{c}{% endequation %} . מכיוון ש-{% equation %}D{% endequation %} סגורה, המשלימה שלה {% equation %}D^{c}{% endequation %} פתוחה ולכן {% equation %}D^{c}{% endequation %} היא סביבה של {% equation %}x{% endequation %} שמוכלת כולה ב-{% equation %}A^{c}{% endequation %} ולכן לא מכילה אף נקודה מ-{% equation %}A{% endequation %}, בסתירה לכך ש-{% equation %}x\in\partial A{% endequation %}, אז הנחת השלילה ש-{% equation %}x\notin D{% endequation %} הייתה שגויה וקיבלנו {% equation %}x\in D{% endequation %}, מה שמסיים את הכיוון הזה של ההוכחה.

עכשיו בואו ניקח נקודה {% equation %}x\in\overline{A}{% endequation %}, נניח שהיא לא ב-{% equation %}A{% endequation %} (כי אם היא כן, סיימנו) ונוכיח שהיא ב-{% equation %}\partial A{% endequation %} . ניקח סביבה {% equation %}U{% endequation %} של {% equation %}x{% endequation %} . מכיוון ש-{% equation %}x{% endequation %} לא ב-{% equation %}A{% endequation %}, הסביבה הזו אוטומטית כוללת איבר מ-{% equation %}A^{c}{% endequation %}, נשאר רק להראות שיש {% equation %}a\in A{% endequation %} ששייך ל-{% equation %}U{% endequation %} . אז בואו נניח בשלילה שאין כזה, כלומר {% equation %}U\subseteq A^{c}{% endequation %}, ולכן {% equation %}A\subseteq U^{c}{% endequation %} . עכשיו כבר אפשר לראות לאן זה הולך: סביבה היא בהגדרה קבוצה פתוחה, ולכן {% equation %}U^{c}{% endequation %} היא קבוצה סגורה, והיא אחת מהקבוצות הסגורות שמכילות את {% equation %}A{% endequation %} ולכן מאלו שהחיתוך שלהן נותן את {% equation %}\overline{A}{% endequation %} . אז קיבלנו {% equation %}x\in\overline{A}\subseteq U^{c}{% endequation %} בסתירה לכך ש-{% equation %}x\in U{% endequation %}, וסיימנו את ההוכחה.

ההוכחה הזו ממחישה יפה את הקושי שיש לפעמים בטופולוגיה. כל צעד כאן הוא פשוט ודי מובן בפני עצמו, אבל לי אישית, למרות שזה עתה כתבתי את ההוכחה הזו מהראש, אין אינטואיציה טובה מה הולך כאן. הכל מרגיש לי כמו משחקים בהגדרות. לא שיש משהו רע בזה... אבל בלי העוגן של מרחבים מטריים, אפשר להבין כמה קל ללכת לאיבוד לפעמים כשהעניינים מסתבכים.

אוקיי, מה עם {% equation %}\text{int}A{% endequation %} ? אנחנו רוצים להוכיח ש-{% equation %}\text{int}A=A\backslash\partial A{% endequation %}, כלומר שהפנים של {% equation %}A{% endequation %} כולל רק את אברי {% equation %}A{% endequation %} שאינם ב-{% equation %}\partial A{% endequation %} . דרך אחרת לנסח את זה היא בתור {% equation %}\text{int}A=A\cap\left(\partial A\right)^{c}{% endequation %}, כלומר הפנים רק את אברי {% equation %}A{% endequation %} שבנוסף לכך גם לא שייכים ל-{% equation %}\partial A{% endequation %} .

הציפייה היא שההוכחה תהיה איכשהו "דואלית" למה שכבר ראינו, הרי כל ההגדרות הן מעין גרסת מראה אחת של השניה, אבל אם ככה - אולי נמצא דרך קיצור ונשתמש במה שכבר הוכחנו, ואולי נלמד דברים חדשים על הדרך?

הטריק הוא באמת ללכת אל הדואלי - כלומר, לקחת משלימים לקבוצות שעובדים איתן. אם {% equation %}\text{int}A{% endequation %} הוא איחוד של קבוצות פתוחות שמוכלות ב-{% equation %}A{% endequation %}, כלומר {% equation %}\text{int}A=\bigcup_{U\subseteq A}U{% endequation %}, אז אם ניקח משלים לשני האגפים ונשתמש בכללי דה-מורגן, נקבל

{% equation %}\left(\text{int}A\right)^{c}=\bigcap_{U\subseteq A}U^{c}{% endequation %} עכשיו, אם {% equation %}U\subseteq A{% endequation %} אז {% equation %}A^{c}\subseteq U^{c}{% endequation %} (נסו להוכיח את זה! זה קל!) כך שאפשר לכתוב את זה גם בתור

{% equation %}\left(\text{int}A\right)^{c}=\bigcap_{A^{c}\subseteq U^{c}}U^{c}{% endequation %} ובגלל שהמשלים של קבוצה פתוחה הוא קבוצה סגורה, אנחנו מקבלים ש-{% equation %}\left(\text{int}A\right)^{c}=\overline{A^{c}}{% endequation %} - המשלים של הפנים של {% equation %}A{% endequation %} הוא הסגור של המשלים של {% equation %}A{% endequation %} (דואליות בפעולה!!!!! אגב, אני לא סתם משתמש במילה הזו, בתורת הקטגוריות יש מהומה שלמה סביב הקונספט הזה).

עכשיו אפשר להשתמש במה שאנחנו כבר יודעים: {% equation %}\left(\text{int}A\right)^{c}=\overline{A^{c}}=A^{c}\cup\partial A^{c}{% endequation %} . לכן, אם ניקח משלים לשני האגפים ונשתמש שוב בדה-מורגן, נקבל

{% equation %}\text{int}A=A\cap\left(\partial A^{c}\right)^{c}{% endequation %} עכשיו, מה זה {% equation %}\partial A^{c}{% endequation %} ? זה כל הנקודות שבכל סביבה שלהן יש נקודה מ-{% equation %}A^{c}{% endequation %} ונקודה מ-{% equation %}\left(A^{c}\right)^{c}=A{% endequation %} . זו... אותה הגדרה בדיוק כמו של {% equation %}\partial A{% endequation %}, אז באופן לא כל כך מפתיע, השפה של {% equation %}A{% endequation %} והשפה של {% equation %}A^{c}{% endequation %} הן אותו דבר, {% equation %}\partial A=\partial A^{c}{% endequation %}, אז קיבלנו

{% equation %}\text{int}A=A\cap\partial A^{c}{% endequation %} וזה בדיוק מה שרצינו. יפה!

עכשיו אפשר להסיק כמה מסקנות. ראשית, {% equation %}A{% endequation %} סגורה אם ורק אם {% equation %}\overline{A}=A{% endequation %} . למה? בכיוון אחד, {% equation %}\overline{A}{% endequation %} סגורה כי היא חיתוך של קבוצות סגורות, אז אם {% equation %}A=\overline{A}{% endequation %}, בוודאי ש-{% equation %}A{% endequation %} סגורה. בכיוון השני, אם {% equation %}A{% endequation %} סגורה אז היא עצמה חלק מהחיתוך שנותן את {% equation %}\overline{A}{% endequation %} וכל קבוצה בחיתוך מכילה את {% equation %}A{% endequation %} אז כל מה שנשאר מהחיתוך הוא {% equation %}A{% endequation %} . באותו אופן מראים ש-{% equation %}A{% endequation %} פתוחה אם {% equation %}A=\text{int}A{% endequation %} .

עכשיו בואו נחזור לנקודות הצטברות. הנה שוב ההגדרה, כדי שתהיה מול העיניים:

- **נקודת הצטברות** של קבוצה {% equation %}A{% endequation %} היא נקודה {% equation %}x{% endequation %} שכל סביבה שלה כוללת איבר של {% equation %}A{% endequation %} ששונה מ-{% equation %}x{% endequation %} .

אנחנו רוצים להראות ש-{% equation %}A{% endequation %} סגורה אם ורק אם היא כוללת כל נקודת הצטברות שלה. אם {% equation %}A{% endequation %} סגורה, אז {% equation %}A=\overline{A}{% endequation %} ולכן {% equation %}A{% endequation %} כוללת את כל **השפה** שלה - ונקודת הצטברות של {% equation %}A{% endequation %} או שייכת אל {% equation %}A{% endequation %} או שהיא בשפה של {% equation %}A{% endequation %}, כי אם {% equation %}x\notin A{% endequation %} היא נקודת הצטברות אז כל סביבה שלה כוללת איבר של {% equation %}A{% endequation %} (כי {% equation %}x{% endequation %} נקודת הצטברות) וגם איבר שאינו של {% equation %}A{% endequation %} (את {% equation %}x{% endequation %} עצמו, כי {% equation %}x\notin A{% endequation %} ). זה נותן כיוון אחד. בכיוון השני, נניח ש-{% equation %}A{% endequation %} כוללת את כל נקודות ההצטברות שלה, אז היא בוודאי תכלול גם את השפה שלה כי כל נקודת שפה שאינה ב-{% equation %}A{% endequation %} היא גם נקודת הצטברות, כי כל סביבה שלה כוללת נקודה ב-{% equation %}A{% endequation %} ואם היא עצמה לא ב-{% equation %}A{% endequation %} הנקודה הזו שונה ממנה. זה מסיים את ההוכחה הזו.

עכשיו אפשר להשלים את רשימת המושגים שהגדרנו בהקשר של מרחבים מטריים ולהגדיר אותם על טהרת המרחבים הטופולוגיים. מה שהתחלתי ממנו היה **גבולות** ובשלב הזה אנחנו כבר יודעים איך לנסח אותם בלי מטריקות:

- אם {% equation %}X{% endequation %} הוא מרחב טופולוגי ו-{% equation %}a_{1},a_{2},a_{3},\ldots\in X{% endequation %} היא סדרת איברים של {% equation %}X{% endequation %}, אומרים שהסדרה מתכנסת לגבול {% equation %}a{% endequation %} ומסמנים זאת {% equation %}\lim_{n\to\infty}a_{n}=a{% endequation %} אם לכל סביבה {% equation %}U{% endequation %} של {% equation %}a{% endequation %} קיים {% equation %}N{% endequation %} כך שלכל {% equation %}n\gt N{% endequation %}, {% equation %}a_{n}\in U{% endequation %} 

- אם {% equation %}X,Y{% endequation %} הם מרחבים טופולוגיים ו-{% equation %}f:X\to Y{% endequation %} פונקציה, אומרים ש-{% equation %}f\left(x\right){% endequation %} שואפת לגבול {% equation %}L\in Y{% endequation %} כאשר {% equation %}x{% endequation %} שואף אל {% equation %}x_{0}\in X{% endequation %} ומסמנים זאת {% equation %}\lim_{x\to x_{0}}f\left(x\right)=L{% endequation %} אם לכל סביבה {% equation %}V\subseteq Y{% endequation %} של {% equation %}L{% endequation %} קיימת סביבה {% equation %}U\subseteq X{% endequation %} של {% equation %}x_{0}{% endequation %} כך ש-{% equation %}f\left(x\right)\in V{% endequation %} לכל {% equation %}x\in U{% endequation %} כך ש-{% equation %}x\ne x_{0}{% endequation %} .

שני אלו הם תרגום כמעט ישיר של הגדרת הגבול ה"רגילה". בגבול רגיל אנחנו לא מדברים על סביבות של {% equation %}x{% endequation %} אלא על כל הנקודות במרחק כלשהו מ-{% equation %}x{% endequation %}, וכבר ראינו ש"סביבה" היא ההכללה הטבעית של זה.

עכשיו אפשר להגיע אל המושג המרכזי שחתרנו אליו - **רציפות**. ההגדרה הרגילה של רציפות היא פשוט {% equation %}\lim_{x\to x_{0}}f\left(x\right)=f\left(x_{0}\right){% endequation %} שזה מה שמתקבל כשלוקחים את הגדרת הגבול הרגילה של פונקציה ומורידים את הדרישה {% equation %}x\ne x_{0}{% endequation %} (ולוקחים {% equation %}L=f\left(x_{0}\right){% endequation %} ).

- אם {% equation %}X,Y{% endequation %} הם מרחבים טופולוגיים ו-{% equation %}f:X\to Y{% endequation %} פונקציה, אומרים ש-{% equation %}f\left(x\right){% endequation %} **רציפה** בנקודה {% equation %}x_{0}{% endequation %} אם לכל סביבה {% equation %}U\subseteq Y{% endequation %} של {% equation %}f\left(x_{0}\right){% endequation %} קיימת סביבה {% equation %}V\subseteq X{% endequation %} של {% equation %}x_{0}{% endequation %} כך ש-{% equation %}f\left(x\right)\in U{% endequation %} לכל {% equation %}x\in V{% endequation %} .

אבל אפשר לעשות משהו מעניין יותר. כפי שהיא מוגדרת כאן, רציפות היא תכונה **נקודתית**. אינטואיטיבית, היא אומרת שהפונקציה "מבטיחה וגם מקיימת" משהו בנקודה {% equation %}x_{0}{% endequation %} : הגבול יוצר את הרושם, ככל שמתקרבים אל {% equation %}x_{0}{% endequation %}, שהפונקציה הולכת להחזיר ערך ספציפי בנקודה {% equation %}x_{0}{% endequation %} - והפלא ופלא, כשמגיעים לשם מתברר שהערך הזה הוא אכן {% equation %}f\left(x_{0}\right){% endequation %} . אבל אפשר גם לדבר על רציפות בתור תכונה של פונקציה בתחום שלם מסוים, או אפילו על כל המרחב. אפשר לנסות לומר ש-{% equation %}f:X\to Y{% endequation %} היא **רציפה** אם היא רציפה ב-{% equation %}x_{0}{% endequation %} לכל {% equation %}x_{0}\in X{% endequation %}, אבל אפשר לנסח את זה גם אחרת.

ראשית, בואו נסתכל על הניסוח של רציפות. אני אומר בסוף "כך ש-{% equation %}f\left(x\right)\in V{% endequation %} לכל {% equation %}x\in U{% endequation %} ". יש דרך אחרת לנסח את הקריטריון הזה בעזרת מושג **המקור** של קבוצה. אם {% equation %}f:X\to Y{% endequation %} היא פונקציה ו-{% equation %}V\subseteq Y{% endequation %}, אז **המקור** של {% equation %}V{% endequation %} תחת {% equation %}f{% endequation %} הוא הקבוצה

- {% equation %}f^{-1}\left(V\right)\triangleq\left\{ x\in X\ |\ f\left(x\right)\in V\right\}{% endequation %} 

כלומר, כל האיברים ב-{% equation %}X{% endequation %} שתחת הפונקציה {% equation %}f{% endequation %} מחזירים משהו ב-{% equation %}V{% endequation %} . שימו לב שה-{% equation %}f^{-1}{% endequation %} שמופיע פה הוא **סימון**; בדרך כלל משתמשים ב-{% equation %}f^{-1}{% endequation %} כדי לתאר את הפונקציה ההופכית של {% equation %}f{% endequation %}, אבל פונקציה הופכית כזו קיימת רק אם {% equation %}f{% endequation %} חח"ע ועל, ואני לא דורש את זה פה. אז הקונבנציה היא שכשכותבים {% equation %}f^{-1}\left(V\right){% endequation %} הכוונה למקור - וקשה להתבלבל כי מבחינה פורמלית אפילו אם {% equation %}f^{-1}{% endequation %} הייתה קיימת, אמורים להפעיל אותה על איברים ולא על קבוצות אם כי כמובן שגם {% equation %}f\left(V\right)\triangleq\left\{ f\left(x\right)\ |\ x\in V\right\}{% endequation %} הוא סימון מקובל עבור **התמונה** של {% equation %}V{% endequation %} תחת {% equation %}f{% endequation %} .

עכשיו, להגיד "כך ש-{% equation %}f\left(x\right)\in V{% endequation %} לכל {% equation %}x\in U{% endequation %} " זה בעצם לומר {% equation %}x\in f^{-1}\left(V\right){% endequation %} לכל {% equation %}x\in U{% endequation %}, כלומר {% equation %}U\subseteq f^{-1}\left(V\right){% endequation %} . לכן בניסוח בעזרת מקור של ההגדרה של רציפות, {% equation %}f\left(x\right){% endequation %} רציפה בנקודה {% equation %}x_{0}{% endequation %} אם לכל סביבה {% equation %}V\subseteq Y{% endequation %} של {% equation %}f\left(x_{0}\right){% endequation %} קיימת סביבה {% equation %}U\subseteq X{% endequation %} של {% equation %}x_{0}{% endequation %} כך ש-{% equation %}U\subseteq f^{-1}\left(V\right){% endequation %} . האם אפשר לפשט את זה עוד? ובכן, כן.

ראשית, בואו נשים לב לכך שאם היה מובטח לי ש-{% equation %}f^{-1}\left(V\right){% endequation %} היא קבוצה **פתוחה**, אז הקריטריון היה מתקיים מאליו: {% equation %}f^{-1}\left(V\right){% endequation %} היא גם קבוצה פתוחה וגם מכילה את {% equation %}x_{0}{% endequation %} (כי {% equation %}f\left(x_{0}\right)\in V{% endequation %} כי כל הרעיון הוא ש-{% equation %}V{% endequation %} היא סביבה של {% equation %}f\left(x_{0}\right){% endequation %} ) ולכן אפשר לבחור {% equation %}U=f^{-1}\left(V\right){% endequation %} ולסיים בזה. אבל האם **מובטח** לנו ש-{% equation %}f^{-1}\left(V\right){% endequation %} היא קבוצה פתוחה, אם {% equation %}f{% endequation %} רציפה?

ובכן, כן.

ברגע שאנחנו עוברים מרציפות נקודתית לרציפות בכל נקודה במרחב, אנחנו כבר לא צריכים לחשוב על {% equation %}V{% endequation %} בתור "הסביבה של {% equation %}x_{0}{% endequation %} ". הקבוצה הפתוחה {% equation %}V{% endequation %} היא הסביבה של **כל** הנקודות שבתוכה. ואפשר להשתמש ברציפות עבור **כל** הנקודות בתוכה שיש להן מקור. לכל {% equation %}x\in f^{-1}\left(V\right){% endequation %} קיימת, על פי הגדרת הרציפות, סביבה {% equation %}U_{x}{% endequation %} כך ש-{% equation %}U_{x}\subseteq f^{-1}\left(V\right){% endequation %} . לכן

{% equation %}\bigcup_{x\in f^{-1}\left(V\right)}U_{x}\subseteq f^{-1}\left(V\right){% endequation %} (כי זה איחוד של קבוצות שכולן מוכלות ב-{% equation %}f^{-1}\left(V\right){% endequation %} ), ומצד שני לכל {% equation %}x\in f^{-1}\left(V\right){% endequation %} קיימת קבוהצ {% equation %}U_{x}{% endequation %} באיחוד שמכילה את {% equation %}x{% endequation %}, כך ש-{% equation %}f^{-1}\left(V\right)=\bigcup_{x\in f^{-1}\left(V\right)}U_{x}{% endequation %} . בפרט, קיבלנו ש-{% equation %}f^{-1}\left(V\right){% endequation %} הוא איחוד של סביבות, כלומר קבוצות פתוחות, {% equation %}f^{-1}\left(V\right){% endequation %} היא קבוצה פתוחה - וזה היה נכון עבור **כל** קבוצה פתוחה {% equation %}V{% endequation %}, כי כל קבוצה פתוחה היא הסביבה של כל הנקודות שלה (אם {% equation %}V{% endequation %} לא הייתה פתוחה, היא לא הייתה סביבה של אף נקודה). זה מוביל אותנו להגדרה האלטרנטיבית הבאה לרציפות, שהיא כנראה ההגדרה המרכזית בטופולוגיה:

- {% equation %}f:X\to Y{% endequation %} היא **רציפה** אם לכל קבוצה פתוחה {% equation %}V\subseteq Y{% endequation %}, המקור {% equation %}f^{-1}\left(V\right){% endequation %} הוא קבוצה פתוחה

ההגדרה הזו עשויה להרגיש קצת מוזרה בהתחלה. על פניו מרגיש טבעי יותר להגדיר ההפך, לא? שאם {% equation %}U\subseteq X{% endequation %} היא קבוצה פתוחה, אז {% equation %}f\left(U\right){% endequation %} גם תהיה פתוחה? אבל לא, לכן לדעתי כדאי לצאת מההגדרה ה"רגילה" לרציפות - אנחנו רואים איך בהגדרה הזו {% equation %}f^{-1}{% endequation %} באה מאליה. אבל זה לא אומר שהתכונה השניה לא חשובה בפני עצמה, ובפרט היא חוזרת לגמרי למשחק כשאנחנו מגדירים את מה שנקרא **הומיאומורפיזם** שנראה לי שכדאי להציג כבר עכשיו.

כשמתחילים ללמוד מתמטיקה, מהר מאוד נתקלים בכל מני פונקציות שנקראות **מורפיזמים**. הרעיון הכללי שמאחורי השם הזה הוא פונקציה בין שני מרחבים שיש להם **מבנה** כלשהו והפונקציה **משמרת** את המבנה הזה (ואז מגיעה **תורת הקטגוריות** ומכלילה את כל הסיפור אבל לא ניכנס לזה הפעם). בפרט נתקלים בשם **איזומורפיזם** כדי לתאר פונקציה שהיא חד-חד-ערכית, על, ומשמרת את המבנה. עכשיו, הקטע בפונקציות חד-חד-ערכיות ועל בין שתי קבוצות {% equation %}A,B{% endequation %} הוא שהן מאפשרות לנו לחשוב על {% equation %}B{% endequation %} בתור "{% equation %}A{% endequation %} אחרי ששינינו שמות לאיברים שלה" (יש לי פוסט על זה [כאן](https://gadial.net/2020/05/15/invertible_functions/)). זה כבר לא עובד עבור פונקציות חח"ע ועל כלליות אם יש על {% equation %}A,B{% endequation %} מבנה כלשהו - למשל אם הם **מרחבים וקטוריים** או **קבוצות סדורות** או **גרפים** או **חבורות** (כל אלו הן סיטואציות שבהן אפשר להיתקל באיזומורפיזמים כבר בתחילת לימודי המתמטיקה). אם מוסיפים את הדרישה הנוספת, של שימור המבנה, אז מקבלים שוב את נקודת המבט של "{% equation %}A{% endequation %} ו-{% equation %}B{% endequation %} הם אותו דבר עד כדי שינוי שמות". בטופולוגיה המילה שבאה לתאר פונקציות כאלו שהן חח"ע, על ומשמרות מבנה היא **הומיאומורפיזם**.

מה ה"מבנה" שרוצים לשמר הפעם? אמרנו שמרחב טופולוגי הוא זוג {% equation %}\left(X,\mathcal{T}_{X}\right){% endequation %} כך ש-{% equation %}X{% endequation %} היא בסך הכל קבוצה, ואילו {% equation %}\mathcal{T}{% endequation %} הוא אוסף של תת-קבוצות של {% equation %}X{% endequation %} שנקראות **קבוצות פתוחות**. אם {% equation %}f{% endequation %} היא הומיאומורפיזם, אז בנוסף לכך שהיא חח"ע ועל היינו רוצים שהיא תשמר קבוצות פתוחות, כלומר אם {% equation %}U\subseteq X{% endequation %} היא פתוחה, שגם {% equation %}f\left(U\right)\subseteq Y{% endequation %} תהיה פתוחה (פורמלית, אם {% equation %}U\in\mathcal{T}_{X}{% endequation %} אז {% equation %}f\left(U\right)\in\mathcal{T}_{Y}{% endequation %} ), אבל זה לבדו לא מספיק, צריך עוד כיוון: שאם {% equation %}U{% endequation %} **איננה** פתוחה גם {% equation %}f\left(U\right){% endequation %} לא תהיה כזו (ולכן אינטואיטיבית אפשר לחשוב על זה כאילו מרחיבים באופן טבעי את {% equation %}f{% endequation %} לפונקציה חח"ע ועל {% equation %}f:\mathcal{T}_{X}\to\mathcal{T}_{Y}{% endequation %} ). עכשיו, אם {% equation %}f{% endequation %} היא חח"ע ועל ו-{% equation %}V\subseteq Y{% endequation %} היא קבוצה כלשהי, אז {% equation %}f^{-1}\left(V\right){% endequation %} זו אותה קבוצה בדיוק בין אם חושבים עליה בתור **המקור** של {% equation %}V{% endequation %} תחת {% equation %}f{% endequation %} במובן שהראיתי קודם, או בתור **התמונה** של {% equation %}f^{-1}{% endequation %} (שעכשיו היא פונקציה אמיתית ולא סתם סימון), כלומר

{% equation %}f^{-1}\left(V\right)=\left\{ x\in X\ |\ f\left(x\right)\in V\right\} =\left\{ f^{-1}\left(y\right)\ |\ y\in V\right\}{% endequation %} זו טענה שצריך להוכיח אבל היא פשוטה (תרגיל!). עבורנו היא מועילה כי עכשיו קל לנסח את התכונה הנוספת שאנחנו מחפשים. אמרתי שאני רוצה לדרוש את "אם {% equation %}U{% endequation %} איננה פתוחה גם {% equation %}f\left(U\right){% endequation %} איננה פתוחה". הטענה הזו שקולה לוגית אל "אם {% equation %}f\left(U\right){% endequation %} פתוחה גם {% equation %}U{% endequation %} פתוחה". עכשיו, אם נסמן {% equation %}V=f\left(U\right){% endequation %}, אז {% equation %}f^{-1}\left(V\right)=f^{-1}\left(f\left(U\right)\right)=U{% endequation %} (זו טענה שצריך להוכיח אבל היא פשוטה), כלומר אפשר לנסח את הדרישה שלנו בתור "אם {% equation %}V\subseteq Y{% endequation %} פתוחה גם {% equation %}f^{-1}\left(V\right){% endequation %} פתוחה". וזו ההגדרה לרציפות שכבר ראינו. אז אפשר להגדיר ש-

- {% equation %}f:X\to Y{% endequation %} היא הומואימורפיזם אם היא חח"ע, על, רציפה ומעבירה קבוצות פתוחות לקבוצות פתוחות

אפשר לנסח את זה אפילו עוד יותר אלגנטי. במקום לומר "חח"ע ועל" מספיק לומר **הפיכה**. ואם לכל {% equation %}U{% endequation %} פתוחה גם {% equation %}f\left(U\right){% endequation %} אז אפשר לנסח את זה גם בתור "לכל {% equation %}U{% endequation %} פתוחה גם {% equation %}\left(f^{-1}\right)^{-1}\left(U\right){% endequation %} פתוחה", כלומר- **המקור** של {% equation %}U{% endequation %} על פי הפונקציה {% equation %}f^{-1}{% endequation %} היא קבוצה פתוחה - מה שאומר ש-{% equation %}f^{-1}{% endequation %} היא **רציפה**. אז אפשר לומר

- {% equation %}f:X\to Y{% endequation %} היא הומואימורפיזם אם היא הפיכה, רציפה, וההופכית שלה גם כן רציפה.

אם יש הומיאומורפיזם {% equation %}f:X\to Y{% endequation %} אומרים ש-{% equation %}X,Y{% endequation %} **הומיאומורפיים**. שימו לב שהמשמעות של זה היא לא ש-{% equation %}X,Y{% endequation %} הם אותו דבר בדיוק, אלא שהם אותו דבר בדיוק בכל הנוגע **לתכונות הטופולוגיות** שלהם. הסיפור הזה עם ספל הקפה שהוא אותו דבר כמו דונאט? פורמלית הוא אומר שהמרחבים שמתארים את ספל הקפה ואת הדונאט הם הומיאומורפיים. זה מוביל באופן טבעי לרצון למצוא קריטריונים נוחים לבדיקה מתי שני מרחבים הם הומיאומורפיים ומתי לא; זה למשל מה ש**טופולוגיה אלגברית** מתעסקת בו כשהיא מגדירה בצורה חכמה מאוד מבנים אלגבריים שמתארים אספקטים מסויימים של המרחב הטופולוגי שנשמרים תחת הומיאומורפיזם.

אני לא הולך לדבר על זה בכלל בשלב הזה.

במקום זה, בואו נראה עוד אפיון של פונקציות רציפות. הגדרתי אותן בעזרת קבוצות **פתוחות**, אבל במרחב טופולוגי לקבוצות הסגורות יש תפקיד חשוב באותה מידה בערך (הרי המשלימה של כל קבוצה פתוחה היא קבוצה סגורה). האם אפשר להגדיר רציפות גם בעזרת קבוצות סגורות? ובכן, בקלות:

- {% equation %}f:X\to Y{% endequation %} היא רציפה אם ורק אם לכל קבוצה סגורה {% equation %}V\subseteq Y{% endequation %}, המקור {% equation %}f^{-1}\left(V\right){% endequation %} הוא קבוצה סגורה

כלומר, בסך הכל לקחתי את ההגדרה הרגילה והחלפתי "פתוחה" ב"סגורה". למה שזה יעבוד? תכונות בסיסיות של משלים שקצת מזכירות את מה שעשיתי בתחילת הפוסט. נניח ש-{% equation %}V{% endequation %} סגורה, אז {% equation %}V^{c}{% endequation %} פתוחה. עכשיו, תכף אראה ש-{% equation %}f^{-1}\left(V^{c}\right)=\left(f^{-1}\left(V\right)\right)^{c}{% endequation %} ולכן אם {% equation %}V{% endequation %} סגורה, אז {% equation %}V^{c}{% endequation %} פתוחה, והרציפות של {% equation %}f{% endequation %} מלמדת ש-{% equation %}f^{-1}\left(V\right){% endequation %} פתוחה, ולכן {% equation %}\left(f^{-1}\left(V\right)\right)^{c}{% endequation %} סגורה. ואת אותו טריק אפשר לעשות גם בכיוון השני של הוכחת השקילות של ההגדרות רק כשהפעם מתחילים עם קבוצה פתוחה ולא סגורה.

למה {% equation %}f^{-1}\left(V^{c}\right)=\left(f^{-1}\left(V\right)\right)^{c}{% endequation %} ? זה כבר סתם להטוטים של תורת הקבוצות: {% equation %}x\in f^{-1}\left(V^{c}\right){% endequation %} אם ורק אם {% equation %}f\left(x\right)\in V^{c}{% endequation %} כלומר אם ורק אם {% equation %}f\left(x\right)\notin V{% endequation %} כלומר אם ורק אם {% equation %}x\notin f^{-1}\left(V\right){% endequation %} כלומר אם ורק אם {% equation %}x\in\left(f^{-1}\left(V\right)\right)^{-1}{% endequation %} . שום דבר חריג פה.

אפשר לסיים פה, אבל למה לא להראות שקילות עוד יותר נחמדה אפילו?

- {% equation %}f{% endequation %} היא רציפה אם ורק אם לכל {% equation %}A\subseteq X{% endequation %} מתקיים {% equation %}f\left(\overline{A}\right)\subseteq\overline{f\left(A\right)}{% endequation %} 

בואו נתחיל מלהניח ש-{% equation %}f{% endequation %} רציפה ונוכיח ש-{% equation %}f\left(\overline{A}\right)\subseteq\overline{f\left(A\right)}{% endequation %} . כלומר, אני לוקח {% equation %}y\in f\left(\overline{A}\right){% endequation %} ורוצה להראות ש-{% equation %}y\in\overline{f\left(A\right)}{% endequation %}, כלומר ש-{% equation %}y{% endequation %} היא נקודת הצטברות של {% equation %}f\left(A\right){% endequation %} . ראשית, {% equation %}y\in\overline{f\left(A\right)}{% endequation %} פירושו שקיים {% equation %}x\in\overline{A}{% endequation %} כך ש-{% equation %}f\left(x\right)=y{% endequation %} . שנית, נקודות הצטברות מוגדרות בעזרת סביבות אז בואו ניקח סביבה {% equation %}V{% endequation %} של {% equation %}y{% endequation %} ונוכיח שיש בה איבר אחד לפחות מ-{% equation %}f\left(A\right){% endequation %} . מכיוון ש-{% equation %}V{% endequation %} קבוצה פתוחה ו-{% equation %}f{% endequation %} רציפה, {% equation %}f^{-1}\left(V\right){% endequation %} היא קבוצה פתוחה שבנוסף לכך גם מקיימת {% equation %}x\in f^{-1}\left(V\right){% endequation %}, כלומר היא סביבה של {% equation %}x{% endequation %} . מכיוון ש-{% equation %}x\in\overline{A}{% endequation %} כל סביבה של {% equation %}x{% endequation %} מכילה נקודה {% equation %}a\in A{% endequation %}, כלומר {% equation %}a\in f^{-1}\left(V\right){% endequation %}, כלומר {% equation %}f\left(a\right)\in V{% endequation %} והנה מצאנו איבר של {% equation %}f\left(A\right){% endequation %} ששייך לסביבה {% equation %}V{% endequation %} . זה מסיים את הכיוון הזה של ההוכחה.

הכיוון השני מעניין יותר (אותי, בגלל שלי אישית מרגיש שהתכונה של {% equation %}f\left(\overline{A}\right)\subseteq\overline{f\left(A\right)}{% endequation %} "חלשה יותר" מאשר רציפות). כדי להוכיח ש-{% equation %}f{% endequation %} רציפה, יותר מתבקש להראות שאם {% equation %}V{% endequation %} **סגורה** אז {% equation %}f^{-1}\left(V\right){% endequation %} סגורה, כי התכונה שכבר יש לי ביד מתעסקת עם סגור ולכן סביר שיהיה יותר קל לדבר על קבוצות סגורות.

התכונה אומרת ש-{% equation %}f\left(\overline{A}\right)\subseteq\overline{f\left(A\right)}{% endequation %}, ואנחנו רוצים לקשר את זה איכשהו אל {% equation %}V{% endequation %} ואל {% equation %}f^{-1}{% endequation %} . בואו נסמן {% equation %}A=f^{-1}\left(V\right){% endequation %}, אז {% equation %}f\left(A\right)=f\left(f^{-1}\left(V\right)\right)\subseteq V{% endequation %} . שימו לב שזה **לא** חייב להיות שוויון, כי בהחלט ייתכן שיש ב-{% equation %}V{% endequation %} איברים שבכלל לא מתקבלים על ידי {% equation %}f{% endequation %} ולכן לא יהיו שייכים ל-{% equation %}f^{-1}\left(V\right){% endequation %} (רק אם {% equation %}f{% endequation %} **על** זה לא יקרה).

עכשיו, המטרה שלנו היא להוכיח ש-{% equation %}A{% endequation %} סגורה, כלומר {% equation %}A=\overline{A}{% endequation %} . בואו ניקח {% equation %}a\in\overline{A}{% endequation %} ונוכיח ש-{% equation %}a\in A{% endequation %} . עכשיו צריך איכשהו להשתמש בנתון {% equation %}f\left(\overline{A}\right)\subseteq\overline{f\left(A\right)}{% endequation %}, אז בואו נפעיל את {% equation %}f{% endequation %} על {% equation %}a{% endequation %} ונקבל:

{% equation %}f\left(a\right)\in f\left(\overline{A}\right)\subseteq\overline{f\left(A\right)}\subseteq\overline{V}=V{% endequation %} כאן השתמשתי בכך שראינו כבר {% equation %}f\left(A\right)\subseteq V{% endequation %} ולכן {% equation %}\overline{f\left(A\right)}\subseteq\overline{V}{% endequation %}, כלומר שלקחת סגור לקבוצה זו פעולה **מונוטונית**. לא הוכחתי את זה קודם אבל זה די ברור: אם {% equation %}A\subseteq B{% endequation %} הן שתי קבוצות כלשהן, אז {% equation %}\overline{B}{% endequation %} היא קבוצה סגורה שמכילה את {% equation %}A{% endequation %}, ולכן היא אחת מהקבוצות שמשתתפות בחיתוך שנותן את {% equation %}\overline{A}{% endequation %} כך ש-{% equation %}\overline{A}\subseteq\overline{B}{% endequation %} .

אוקיי, אז מה קיבלנו? {% equation %}f\left(a\right)\in V{% endequation %} מילולית אומר ש-{% equation %}a\in f^{-1}\left(V\right)=A{% endequation %}, וזה בדיוק מה שרצינו. זה מסיים את ההוכחה של הטענה הזו.

לסיום, בואו נראה שתי תוצאות שימושיות על איך להראות שפונקציות הן רציפות שאצטרך כבר בפוסט הבא אבל עדיף להראות אותן עכשיו כדי לא לקטוע את הזרימה בו ולהיעזר בכך שכרגע אנחנו עדיין זוכרים את ההגדרה.

ראשית, אם רוצים להוכיח שפונקציה {% equation %}f:X\to Y{% endequation %} היא רציפה ישירות מתוך ההגדרה, לכל תת-קבוצה {% equation %}V\subseteq Y{% endequation %} פתוחה צריך להראות ש-{% equation %}f^{-1}\left(V\right){% endequation %} פתוחה. זה מעיק, כי קבוצות פתוחות יכולות להיות די מסובכות - לכן טוב לדעת שאפשר להצמצם רק לבסיסים/תת-בסיסים של הטופולוגיה. כלומר: אם {% equation %}\mathcal{B}{% endequation %} הוא תת-בסיס או בסיס של {% equation %}\left(Y,\mathcal{T}_{Y}\right){% endequation %} אז מספיק להראות ש-{% equation %}f^{-1}\left(B\right){% endequation %} פתוחה ב-{% equation %}X{% endequation %} לכל {% equation %}B\in\mathcal{B}{% endequation %} כדי להוכיח ש-{% equation %}f{% endequation %} רציפה.

ההוכחה של זה תעבור דרך תכונות תורת-קבוצתיות של פונקציות, כמו שהשתמשתי קודם ב-{% equation %}f^{-1}\left(V^{c}\right)=\left(f^{-1}\left(V\right)\right)^{c}{% endequation %} . איך {% equation %}f^{-1}{% endequation %} משחק עם חיתוכים ואיחודים? ובכן, בדיוק באותה צורה, באופן האופטימלי ביותר שאפשר:

- {% equation %}f^{-1}\left(\bigcup B_{i}\right)=\bigcup f^{-1}\left(B_{i}\right){% endequation %} 

- {% equation %}f^{-1}\left(\bigcap B_{i}\right)=\bigcap f^{-1}\left(B_{i}\right){% endequation %} 

ההוכחה היא שרשרת אם-ורק-אם פשוטה, ממש ברמת תורת הקבוצות של סמסטר ראשון:

{% equation %}x\in f^{-1}\left(\bigcup B_{i}\right)\iff f\left(x\right)\in\bigcup B_{i}\iff\exists i:f\left(x\right)\in B_{i}\iff{% endequation %}

{% equation %}\iff\exists i:x\in f^{-1}\left(B_{i}\right)\iff x\in\bigcup f^{-1}\left(B_{i}\right){% endequation %} ובאופן דומה גם עבור חיתוכים.

המסקנה? אם {% equation %}\mathcal{B}{% endequation %} בסיס/תת-בסיס של {% equation %}Y{% endequation %} ו-{% equation %}V\subseteq Y{% endequation %} פתוחה, אז מכיוון שאפשר לכתוב את {% equation %}V{% endequation %} בעזרת איחודים וחיתוכים של אברי {% equation %}\mathcal{B}{% endequation %} נקבל ש-{% equation %}f^{-1}\left(V\right){% endequation %} הוא איחודים וחיתוכים של הפעלת {% equation %}f^{-1}{% endequation %} על אברי {% equation %}\mathcal{B}{% endequation %}, כך שאם כולם פתוחים נקבל שגם {% equation %}f^{-1}\left(V\right){% endequation %} פתוחה.

שנית, אם {% equation %}f:X\to Y{% endequation %} ו-{% equation %}g:Y\to Z{% endequation %} הן פונקציות רציפות אז גם ההרכבה {% equation %}gf{% endequation %} היא רציפה (יש כאלו שכותבים הרכבה בתור {% equation %}f\circ g{% endequation %} או {% equation %}g\circ f{% endequation %} ; אני אוותר על זה כאן. המשמעות של {% equation %}gf{% endequation %} היא הפונקציה שבה קודם מפעילים את {% equation %}f{% endequation %} ואז מפעילים את {% equation %}g{% endequation %} על התוצאה). זו תוצאה סטנדרטית בחשבון אינפיניטסימלי אבל שם מוכיחים את זה עם אפסילון-דלתא; בואו נעשה את זה עם ההגדרה הכללית יותר. צריך להיות טיפה זהירים עם מה זה בדיוק אומר {% equation %}\left(gf\right)^{-1}{% endequation %} אבל זו תהיה הוכחה די פשוטה. נתחיל עם {% equation %}W\subseteq Z{% endequation %} פתוחה. 

עכשיו, בואו נסמן {% equation %}V=g^{-1}\left(W\right){% endequation %} ו-{% equation %}U=f^{-1}\left(V\right){% endequation %} . אם {% equation %}W{% endequation %} פתוחה, אז {% equation %}V{% endequation %} פתוחה כי {% equation %}g{% endequation %} רציפה, ולכן {% equation %}U{% endequation %} פתוחה כי {% equation %}f{% endequation %} רציפה; אם אני אראה ש-{% equation %}\left(gf\right)^{-1}=U{% endequation %}, סיימתי. עכשיו, על פי ההגדרה:

{% equation %}\left(gf\right)^{-1}\left(W\right)=\left\{ x\in X\ |\ g\left(f\left(x\right)\right)\in W\right\}{% endequation %} מצד אחד, אם {% equation %}x\in U{% endequation %} אז {% equation %}f\left(x\right)\in V{% endequation %} ולכן {% equation %}g\left(f\left(x\right)\right)\in W{% endequation %}, כלומר {% equation %}x\in\left(gf\right)^{-1}\left(W\right){% endequation %} .

מצד שני, אם {% equation %}x\in\left(gf\right)^{-1}\left(W\right){% endequation %} ואני מסמן {% equation %}y=f\left(x\right){% endequation %} אז אני יודע ש-{% equation %}g\left(y\right)\in W{% endequation %} כלומר {% equation %}y\in g^{-1}\left(W\right)=V{% endequation %} . קיבלתי ש-{% equation %}f\left(x\right)\in V{% endequation %} ולכן {% equation %}x\in f^{-1}\left(V\right)=U{% endequation %} וזה מסיים את ההוכחה.

האם זה כל מה שיש להגיד על פונקציות רציפות? בוודאי שלא, אבל בשביל להגיד עוד דברים אני צריך עוד סוגי מרחבים לדבר עליהם, ואל זה נגיע בפוסט הבא.
